Осторожно

Типичные ошибки

  1. P · l — только для прямой призмы
  2. правильная пирамида — высота в центр основания
  3. r — для апофемы, R — для бокового ребра
  4. в S_бок — апофема, не высота
  5. равные диагонали — только у прямоугольного параллелепипеда
  6. тетраэдр: медианы 3 : 1

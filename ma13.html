Алгебра · § 13

Степень с рациональным показателем

§ 13 · a^(m/n) = ⁿ√aᵐ, свойства степеней, функция y = xʳ, преобразования выражений

▶ Презентация Рабочий лист Домашнее задание

Теория

Что мы уже знаем о степенях

Для натурального показателя an — произведение n множителей. Потом появились a0 = 1 и a−n = 1/an (a ≠ 0). Эти определения выбраны так, чтобы сохранились пять свойств:

  • am · an = am+n;
  • am : an = am−n;
  • (am)n = amn;
  • (ab)n = anbn;
  • (a/b)n = an/bn.

Дробный показатель

Хотим, чтобы свойства сохранились и для дробей. Пусть x = 22/3. Если свойство (ap)q = apq верно, то x³ = (22/3)³ = 2² = 4, то есть x = 3√4. Это подсказывает определение.

Определение

Степенью положительного числа a с рациональным показателем r = m/n (m ∈ Z, n ∈ N, n > 1) называют число n√am:   am/n = n√am.

Для нуля: 0m/n = 0 при m/n > 0.

Примеры: 53/4 = 4√5³, 3−1/5 = 5√3⁻¹ = 5√(1/3), 82/3 = 3√64 = 4. Значение не зависит от того, какой дробью записан показатель: 84/6 = 6√8⁴ = 3√8² = 4 (теорема 12.6).

Будь внимателен

Степень с дробным показателем определена только для положительного основания (и для нуля — при положительном показателе). Запись (−8)1/3 не определена, хотя 3√(−8) = −2 существует. Если бы мы разрешили (−8)1/3 = −2, то получили бы противоречие: (−8)1/3 = (−8)2/6 = 6√(−8)² = 6√64 = 2. А 0−1/2 не имеет смысла: делить на ноль нельзя.

Функция y = xʳ

Функцию y = xr, r ∈ Q, называют степенной функцией с рациональным показателем. При r = m/n > 0 (дробь несократимая, n > 1) область определения [0; +∞), при r < 0 — (0; +∞).

Функции y = 3√x и y = x1/3 совпадают на [0; +∞), но первая определена ещё и для отрицательных x.

Свойства степени с рациональным показателем

Теоремы 13.1–13.4

Для любых a > 0, b > 0 и рациональных p, q:

ap · aq = ap+q;   ap : aq = ap−q;   (ap)q = apq;   (ab)p = apbp;   (a/b)p = ap/bp.

Доказательство

Докажем первое. Приведём показатели к общему знаменателю: p = m/n, q = k/n. Тогда ap · aq = n√am · n√ak = n√am+k = a(m+k)/n = ap+q.

Разбор примеров

Пример 1 · вычислить

Вычисли: 272/3; 16−3/4; 0,04−1/2; (1/32)−0,4.

Решение

272/3 = (3√27)² = 9; 16−3/4 = 1/(4√16)³ = 1/8; 0,04−1/2 = 1/√0,04 = 1/0,2 = 5; (1/32)−0,4 = 322/5 = (5√32)² = 4.

Удобно сначала извлечь корень, потом возводить в степень — числа получаются меньше.

Пример 2 · упростить

Упрости: а) a1/3 · a1/2; б) (a3/4)8/3; в) a2/3 · a1/6 : a1/2.

Решение

а) a1/3 + 1/2 = a5/6; б) a3/4 · 8/3 = a²; в) a2/3 + 1/6 − 1/2 = a1/3.

Пример 3 · сократить дробь

Сократи дробь (a − 4b) / (a1/2 + 2b1/2).

Решение

a = (a1/2)², 4b = (2b1/2)². Числитель — разность квадратов: (a1/2 − 2b1/2)(a1/2 + 2b1/2). Ответ: a1/2 − 2b1/2.

Пример 4 · уравнение

Реши уравнения: а) x2/3 = 4; б) 3√x² = 4.

Решение

а) x2/3 определено только при x ≥ 0. Возведём в степень 3/2: x = 43/2 = 8.

б) 3√x² определено при всех x: x² = 64, x = ±8.

Будь внимателен

Записи 3√x² и x2/3 равны только при x ≥ 0. Заменяя корень дробной степенью, следи, чтобы не потерять отрицательные значения.

Пример 5 · сравнить

Что больше: 21/2 или 31/3?

Решение

Возведём оба положительных числа в шестую степень (функция t6 возрастает при t > 0): (21/2)⁶ = 8, (31/3)⁶ = 9. Значит, 31/3 > 21/2.

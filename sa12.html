§ 12

Показательные уравнения

Неизвестное — в показателе степени

Главное свойство

Одно основание — равные показатели

Свойствоax₁ = ax₂  ⇔  x₁ = x₂  (a > 0, a ≠ 1)

Почему: показательная функция монотонна и каждое значение принимает один раз.

Способ 1

Одно основание

  1. 9·3x = 1/3 ⇒ 3x+2 = 3−1 ⇒ x = −3
  2. 25x = (1/5)x−3 ⇒ 52x = 5−x+3 ⇒ x = 1
  3. 2x²−3x = 2−2 ⇒ x = 1, x = 2

Способ 2

За скобки

2x+2 − 2x = 24

2x(4 − 1) = 24 ⇒ 2x = 8 ⇒ x = 3

Выносим степень с наименьшим показателем.

Способ 3

Разные основания

2x·5x = 10x = 1000 ⇒ x = 3

5x = 3x  : 3x > 0 ⇒ (5/3)x = 1 ⇒ x = 0

Способ 4

Замена t = 2ˣ

  1. 4x − 3·2x − 4 = 0,  4x = (2x)²
  2. t² − 3t − 4 = 0 ⇒ t = 4 или t = −1
  3. t > 0, поэтому t = −1 отбрасываем
  4. 2x = 4 ⇒ x = 2

Графически

2ˣ = 3 − x

Подбором: x = 1.

С чего начать

Основные понятия

Определения строятся по принципу «новое — через старое». Значит, первые понятия приходится принять без определения.

В стереометрии их три: точка, прямая, плоскость.

Пространство не плоское

АксиомыА1. Для любой плоскости есть точка, ей не принадлежащая.

А2. В любой плоскости пространства выполняются все аксиомы (а значит, и теоремы) планиметрии.

А3 · А4

Три точки и рейка

АксиомыА3. Через три точки, не лежащие на одной прямой, проходит единственная плоскость.

А4. Две точки прямой в плоскости ⟹ вся прямая в плоскости.

А5 · А6

Плоскости и расстояния

АксиомыА5. Две плоскости с общей точкой пересекаются по прямой.

А6. Расстояние между двумя точками одинаково в любой плоскости через них.

Пример

Одна плоскость или бесконечно много?

  1. AB = 3, BC = 4, AC = 5: ни одна длина не равна сумме двух других — треугольник ⟹ плоскость одна
  2. AB = 2, BC = 5, AC = 7: 2 + 5 = 7 — точки на одной прямой ⟹ плоскостей бесконечно много

Как узнать правильный многогранник, почему их пять и как проверять числа граней, рёбер и вершин?

Три условия правильности

  • Многогранник выпуклый.
  • Все грани - равные правильные многоугольники.
  • В каждой вершине сходится одинаковое число рёбер.

Проверяем все условия вместе.

Пять возможных тел

Треугольные грани: правильный тетраэдр, октаэдр, икосаэдр.

Квадратные грани: куб (гексаэдр).

Пятиугольные грани: правильный додекаэдр.

Плоские углы при вершине

n - число сторон грани, k - число граней при вершине.

α = 180°(n − 2)n

kα < 360°, n ≥ 3, k ≥ 3.

Это углы внутри граней; знак неравенства строгий.

Пять пар (n, k)

Треугольник: (3, 3), (3, 4), (3, 5).

Квадрат: (4, 3).

Пятиугольник: (5, 3).

При n ≥ 6 уже три угла дают не менее 360°.

Двойной подсчёт

Г - граней, Р - рёбер, В - вершин.

nГ = 2Р: каждое ребро общее для двух граней.

kВ = 2Р: у каждого ребра два конца.

Проверка Эйлера

Для выпуклого многогранника:

В − Р + Г = 2.

Для правильного тела также:

Р(2k + 2n − 1) = 2.

Проверка чисел не заменяет определения правильности.

Каркас, поверхность, двойственность

L = Рa, S = ГSграни.

Треугольная грань: Sграни = a2√34.

Куб ↔ октаэдр; додекаэдр ↔ икосаэдр; тетраэдр ↔ тетраэдр.

При двойственности В и Г меняются местами, Р сохраняется.

Порядок самостоятельного решения

  1. Проверить условия определения.
  2. Указать n, k и проверить сумму углов.
  3. Выбрать равенства для В, Р, Г.
  4. Записать единицы и проверить результат.

Для практики и домашней работы нужно обоснование, а не только название тела.

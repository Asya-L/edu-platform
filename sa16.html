Свойства логарифмов

Логарифм — показатель, поэтому правила те же, что у степеней

Три свойства

b > 0, c > 0

Свойстваloga(bc) = loga b + loga c
loga(b/c) = loga b − loga c
loga bp = p·loga b

am·an = am+n  →  логарифмы складываются

Ловушка

Таких свойств нет

loga(b + c) ≠ loga b + loga c

(loga b)² ≠ 2loga b

log2(4 + 4) = 3, а log2 4 + log2 4 = 4

Слева направо

  1. loga b = 2,  loga c = 3
  2. loga(b²c) = 2·2 + 3 = 7
  3. loga(b³/c²) = 3·2 − 2·3 = 0

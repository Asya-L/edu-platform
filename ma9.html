Алгебра · § 9

Степенная функция с натуральным показателем

§ 9 · y = xⁿ, n ∈ N: чётный и нечётный показатель, сравнение степеней, наибольшее и наименьшее значения

▶ Презентация Рабочий лист Домашнее задание

Теория

Функции y = x и y = x² ты знаешь давно. Обе — частные случаи функции y = xn, n ∈ N, которую называют степенной функцией с натуральным показателем. Выражение xn имеет смысл при любом x, поэтому область определения — R. Нуль у функции один: x = 0. Остальные свойства зависят от того, чётный показатель или нечётный.

Чётный показатель: n = 2k

  • Область значений [0; +∞): чётная степень любого числа неотрицательна, и любое a ≥ 0 получается (при x = n√a, см. § 11);
  • знак: y > 0 на (−∞; 0) и на (0; +∞);
  • чётная функция: (−x)2k = x2k, график симметричен относительно оси Oy;
  • убывает на (−∞; 0], возрастает на [0; +∞).

Почему возрастает на [0; +∞)? Если 0 ≤ x₁ < x₂, то, перемножив неравенство само на себя n раз (все части неотрицательны), получим x₁n < x₂n. А на (−∞; 0] работает симметрия: чем дальше от нуля, тем больше значение.

Нечётный показатель: n = 2k + 1

  • Область значений R;
  • знак: y < 0 на (−∞; 0), y > 0 на (0; +∞) — знак степени совпадает со знаком основания;
  • нечётная функция: (−x)2k+1 = −x2k+1, график симметричен относительно начала координат;
  • возрастает на всей прямой.

Разбор примеров

Сравнение степеней

Монотонность позволяет сравнивать значения, не вычисляя их. Для нечётного n: x₁ < x₂ ⇔ x₁n < x₂n при любых числах. Для чётного n сравнивают модули: |x₁| < |x₂| ⇔ x₁n < x₂n.

Пример 1 · сравнить

а) Сравни (−3,5)⁸ и 2,9⁸. б) Сравни (−2)⁷ и (−1,5)⁷.

Решение

а) Показатель чётный — сравниваем модули: 3,5 > 2,9, значит, (−3,5)⁸ > 2,9⁸.

б) Показатель нечётный, функция возрастает: −2 < −1,5, значит, (−2)⁷ < (−1,5)⁷.

Будь внимателен

Для чётной степени из x₁ < x₂ не следует x₁n < x₂n: −3 < 2, но (−3)² = 9 > 2² = 4. Смотри на модули или на то, по одну ли сторону от нуля лежат числа.

Наибольшее и наименьшее значения

Пример 2 · на промежутке

Найди наибольшее и наименьшее значения f(x) = x⁴ на а) [−3; −1]; б) [−2; 1]; в) (−2; 1).

Решение

а) На [−3; −1] функция убывает: наибольшее f(−3) = 81, наименьшее f(−1) = 1.

б) Внутри отрезка есть точка 0, где функция меняет монотонность: наименьшее f(0) = 0; наибольшее — на одном из концов: f(−2) = 16, f(1) = 1, значит, 16.

в) Наименьшее по-прежнему 0. А наибольшего нет: значения сколь угодно близки к 16, но точка −2 в промежуток не входит.

Уравнения

Пример 3 · простейшие

Реши уравнения: а) x⁷ = −128; б) x⁴ = 81; в) x⁶ = −1.

Решение

а) Показатель нечётный, функция возрастает и принимает каждое значение ровно один раз: (−2)⁷ = −128, x = −2.

б) Показатель чётный: 81 > 0, корней два, противоположных: x = ±3.

в) Чётная степень не бывает отрицательной: корней нет.

Пример 4 · угадать и доказать единственность

Реши уравнение x⁵ + x³ = 2.

Решение

Корень 1 угадывается: 1 + 1 = 2. Других нет: функции x⁵ и x³ возрастают, их сумма тоже возрастает, а возрастающая функция каждое значение принимает только один раз. Ответ: 1.

Будь внимателен

В примере 4 мало угадать корень — нужно объяснить, почему других нет. Без фразы про возрастание решение неполное.

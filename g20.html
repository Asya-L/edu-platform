Компланарные векторы. Разложение вектора

п. 43–45 · компланарные векторы и их признак, правило параллелепипеда, разложение вектора по трём некомпланарным векторам

▶ Презентация Рабочий лист Домашнее задание

Теория

На плоскости любой вектор можно выразить через два неколлинеарных (это было в 9 классе). В пространстве «направлений» больше, и двух векторов уже не хватает: вектор, торчащий из плоскости, через два вектора этой плоскости не выразить. Нужен третий — и вот тут появляется понятие компланарности.

Компланарные векторы

Определение

Векторы называются компланарными, если при откладывании от одной и той же точки они лежат в одной плоскости.

Другими словами, векторы компланарны, если существует плоскость, которой они все параллельны (лежат в ней или на прямых, ей параллельных). Слово от латинского com — «вместе» и planum — «плоскость».

  • любые два вектора компланарны (через две пересекающиеся прямые, на которых они лежат после откладывания от одной точки, проходит плоскость);
  • три вектора, среди которых есть два коллинеарных, компланарны;
  • в параллелепипеде ABCDA₁B₁C₁D₁ векторы AB, AD, A₁C₁ компланарны (все параллельны плоскости ABC), а AB, AD, AA₁ — не компланарны.
Признак компланарности

Если вектор c можно разложить по векторам a и b, т. е. представить в виде c = xa + yb, где x, y — числа, то векторы a, b, c компланарны.

Доказательство

Если a и b коллинеарны, то c = xa + yb коллинеарен им, и все три лежат на одной прямой после откладывания от одной точки — компланарны. Пусть a и b не коллинеарны. Отложим от точки O векторы OA = xa и OB = yb. Оба лежат в плоскости α, проходящей через O параллельно a и b. По правилу параллелограмма их сумма OC = c — диагональ параллелограмма, который лежит в той же плоскости α. Значит, a, b, c, отложенные от O, лежат в α. ∎

Верно и обратное: если векторы a, b, c компланарны, а a и b не коллинеарны, то c единственным образом раскладывается по a и b — это планиметрическая теорема о разложении, применённая в их общей плоскости.

Будь внимателен

«Компланарны» не значит «лежат в одной плоскости там, где нарисованы». Векторы AB и C₁D₁ на чертеже лежат на разных гранях, но коллинеарны, а значит, компланарны с любым третьим вектором. Всегда мысленно откладывай векторы от одной точки.

Правило параллелепипеда

Правило параллелепипеда

Если векторы a, b, c не компланарны и отложены от одной точки: AB = a, AD = b, AA₁ = c, а на них построен параллелепипед ABCDA₁B₁C₁D₁, то a + b + c = AC₁ — диагонали параллелепипеда, выходящей из общего начала.

Доказательство

AB + AD = AC по правилу параллелограмма (грань ABCD). AA₁ = CC₁ (грань AA₁C₁C — параллелограмм). По правилу треугольника AC + CC₁ = AC₁. ∎

Разложение вектора по трём некомпланарным векторам

Что значит «разложить»

Если вектор p представлен в виде p = xa + yb + zc, где x, y, z — числа, говорят, что p разложен по векторам a, b, c; числа x, y, z — коэффициенты разложения.

Теорема

Любой вектор можно разложить по трём данным некомпланарным векторам, причём коэффициенты разложения определяются единственным образом.

Доказательство

Существование. Отложим a, b, c и p = OP от точки O. Векторы a, b задают плоскость α через O. Через P проведём прямую, параллельную c; она пересечёт α в точке P₁ (она не параллельна α, иначе c лежал бы в α). Тогда OP = OP₁ + P₁P. Вектор P₁P коллинеарен c: P₁P = zc. Вектор OP₁ лежит в α, по планиметрии OP₁ = xa + yb. Итак, p = xa + yb + zc.

Единственность. Пусть есть ещё разложение p = x₁a + y₁b + z₁c. Вычтем: 0 = (x − x₁)a + (y − y₁)b + (z − z₁)c. Если, например, z ≠ z₁, то c выражается через a и b, и по признаку все три вектора компланарны — противоречие. Значит, z = z₁, и так же x = x₁, y = y₁. ∎

Как раскладывать на практике. В параллелепипеде ABCDA₁B₁C₁D₁ обычно берут a = AB, b = AD, c = AA₁. Удобно представить себе, что A — «начало отсчёта», а каждая вершина получается из A шагами вдоль рёбер:

ВершинаВектор из AВершинаВектор из A
BaA₁c
DbB₁a + c
Ca + bD₁b + c
C₁a + b + c

Тогда любой вектор XY между вершинами — это (вектор из A в Y) − (вектор из A в X): XY = AY − AX. Например, BD₁ = (b + c) − a = −a + b + c. Для середины M отрезка XY: AM = ½(AX + AY).

Будь внимателен

Знак коэффициента зависит от направления: DB₁ = a − b + c, а B₁D = −a + b − c. Проверяй по таблице «конец минус начало».

Будь внимателен

Разложение единственно только по некомпланарным векторам. По трём компланарным векторам вектор, не параллельный их плоскости, не раскладывается вовсе, а лежащий в ней — раскладывается многими способами.

Разбор примеров

Пример 1 · компланарны ли векторы

Дан куб ABCDA₁B₁C₁D₁. Компланарны ли векторы AB₁, AD₁ и BD?

Решение

Разложим по a = AB, b = AD, c = AA₁: AB₁ = a + c, AD₁ = b + c, BD = b − a. Заметим: AD₁ − AB₁ = b − a = BD. Вектор BD выразился через AB₁ и AD₁ — по признаку векторы компланарны. (Геометрически: BD = B₁D₁, а B₁D₁ лежит в плоскости AB₁D₁.)

Пример 2 · раскладываем в параллелепипеде

Дан параллелепипед ABCDA₁B₁C₁D₁, a = AB, b = AD, c = AA₁. Разложи по a, b, c векторы A₁C и AM, где M — центр грани A₁B₁C₁D₁.

Решение

A₁C = AC − AA₁ = a + b − c.

M — середина диагонали A₁C₁: AM = ½(AA₁ + AC₁) = ½(c + a + b + c) = ½a + ½b + c.

Пример 3 · точка пересечения медиан грани

В тетраэдре DABC точка G — точка пересечения медиан треугольника ABC. Разложи DG по DA, DB, DC.

Решение

Пусть K — середина BC. Медианы делятся точкой пересечения в отношении 2 : 1, поэтому AG = ⅔AK = ⅔ · ½(AB + AC) = ⅓(AB + AC).

AB = DB − DA, AC = DC − DA. Тогда DG = DA + AG = DA + ⅓(DB + DC − 2DA) = ⅓(DA + DB + DC).

Пример 4 · длина через разложение

Измерения прямоугольного параллелепипеда ABCDA₁B₁C₁D₁: AB = 2, AD = 4, AA₁ = 8; K — середина ребра CC₁. Разложи AK по a = AB, b = AD, c = AA₁ и найди |AK|.

Решение

AK = AC + CK = a + b + ½c. Это диагональ прямоугольного параллелепипеда с измерениями 2, 4 и ½ · 8 = 4: |AK| = √(4 + 16 + 16) = 6.

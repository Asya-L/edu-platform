Внимание

Почему a > 0

(−8)1/3 = −2?  Но 1/3 = 2/6, а (−8)2/6 = ⁶√64 = 2.

Противоречие — поэтому для отрицательных оснований дробные показатели не используют.

Свойства

a > 0, b > 0

  1. ap·aq = ap+q,   ap : aq = ap−q
  2. (ap)q = apq
  3. (ab)p = apbp

a1/3·a1/2 : a1/6 = a2/3

Сравнение

Какая степень больше

  1. a > 1: больше показатель — больше степень: 2√3 > 21,7
  2. 0 < a < 1: наоборот: 0,5³ < 0,5²
  3. ³√3 = ⁶√9 > ⁶√8 = √2

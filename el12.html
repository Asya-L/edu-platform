Функции и их графики

линейная, квадратичная, обратная пропорциональность, корень, показательная и логарифмическая: коэффициенты по графику

▶ Презентация Рабочий лист Домашнее задание

Главный приём

  1. Определить вид функции по рисунку (подпись обычно дана).
  2. Найти на графике точки в узлах сетки — сколько неизвестных коэффициентов, столько и точек.
  3. Подставить точки в формулу, решить систему.
  4. Записать формулу и вычислить то, что спрашивают (значение в точке, корень, пересечение).
Будь внимателен

Берите только точки, которые точно лежат в узлах сетки. Точку «примерно на 1,5» использовать нельзя — ответ получится неверным.

Пример 1 · парабола

На рисунке — график f(x) = ax² + bx + c. Найдите f(7).

Решение

Точки (0; 1), (1; −2), (2; −3): c = 1; a + b = −3; 4a + 2b = −4 → a = 1, b = −4. f(x) = x² − 4x + 1, f(7) = 49 − 28 + 1 = 22.

Пример 2 · гипербола

На рисунке — график f(x) = k/x + a. Найдите f(10).

Решение

Точки (1; 3) и (2; 2): k + a = 3, k/2 + a = 2 → k = 2, a = 1. f(10) = 0,2 + 1 = 1,2.

Пример 3 · пересечение

На рисунке — две прямые. Найдите ординату их точки пересечения.

Решение

Синяя: через (0; 0) и (2; 1) → y = 0,5x. Оранжевая: через (0; 4) и (2; 0) → y = −2x + 4. 0,5x = −2x + 4 → x = 1,6, y = 0,8.

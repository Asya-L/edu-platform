§ 13

Показательные неравенства

Посмотри на основание — потом на знак

Правило

Знак зависит от основания

Правилоa > 1:  af > ag ⇔ f > g  ·  0 < a < 1:  af > ag ⇔ f < g

Почему: при a > 1 функция возрастает, при 0 < a < 1 — убывает.

Примеры

Одно основание

  1. 3x ≤ 3−2, 3 > 1 ⇒ x ≤ −2
  2. (1/3)x > (1/3)−3, 1/3 < 1 ⇒ x < −3
  3. 2x²−2x < 2³ ⇒ x² − 2x − 3 < 0 ⇒ (−1; 3)

Степень всегда > 0

5x > −2 — верно при всех x

0,3x ≤ 0 — решений нет

Замена

4ˣ − 3·2ˣ − 4 < 0

  1. t = 2x > 0: t² − 3t − 4 < 0
  2. −1 < t < 4, с учётом t > 0: 0 < t < 4
  3. 2x < 2² ⇒ x < 2

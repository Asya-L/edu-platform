Домашняя работа: учитель увидит результат первой попытки.

1. N — положительное целое число. Если N чётное, дописываем справа 01; если нечётное — 10. Полученную двоичную запись переводим в десятичное число R. Чему равно R при N = 9? Ответ запиши в десятичной системе.

2. N — положительное целое число. Если N чётное, дописываем справа 01; если нечётное — 10. Полученную двоичную запись переводим в десятичное число R. Найди наименьшее N, при котором R > 58. Ответ запиши в десятичной системе.

3. N — положительное целое число. Дважды подряд дописываем справа остаток от деления числа единиц в текущей записи на 2. Второй раз пересчитываем единицы после первой дописки. Полученную двоичную запись переводим в десятичное число R. Чему равно R при N = 5? Ответ запиши в десятичной системе.

4. N — положительное целое число. Дважды подряд дописываем справа остаток от деления числа единиц в текущей записи на 2. Второй раз пересчитываем единицы после первой дописки. Полученную двоичную запись переводим в десятичное число R. Найди наименьшее значение R, строго большее 54. Ответ запиши в десятичной системе.

5. N — положительное целое число. Если N делится на 3, дописываем справа 00. Иначе дописываем справа двоичную запись удвоенного остатка N от деления на 3, без ведущих нулей. Полученную двоичную запись переводим в десятичное число R. Найди наименьшее N, при котором R > 51. Ответ запиши в десятичной системе.

6. N — положительное целое число. Если N делится на 3, дописываем справа 00. Иначе дописываем справа двоичную запись удвоенного остатка N от деления на 3, без ведущих нулей. Полученную двоичную запись переводим в десятичное число R. Найди наименьшее значение R, строго большее 52. Ответ запиши в десятичной системе.

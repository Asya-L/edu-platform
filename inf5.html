Двоичные алгоритмы

Переводим числа, меняем двоичные записи и решаем задачи вручную и на Python.

СлайдыРабочий листТеорияЗадачи парамиДомашкаСамопроверка

Разминка

Запиши ход вычислений. В Р3 объясни оба ответа отдельно.

Р1Переведи 13 в двоичную систему последовательным делением на 2.
Р2Переведи 10110₂ в десятичную систему через сумму степеней двойки.
Р3Даны записи 1010₂ и 1011₂. У какой число чётное? В какой записи чётное количество единиц?
Р4К записи 101₂ допиши справа сначала 1, затем 0. Запиши итоговую строку и её значение.

Теория и разобранные примеры

Как читать условие

Исходное число N → его двоичная запись s → изменённая запись → десятичное число R. Перед вычислениями подчеркни, что ищешь: N или R, минимум или максимум, строгая или нестрогая граница.

1. Перевод и чётность

Справа налево веса двоичных разрядов равны 1, 2, 4, 8, 16 и так далее. При переводе из десятичной системы дели на 2 и читай остатки от последнего к первому.

Разбор · N = 18

18 = 2 · 9 + 0, 9 = 2 · 4 + 1, 4 = 2 · 2 + 0, 2 = 2 · 1 + 0, 1 = 2 · 0 + 1. Читаем остатки снизу вверх: 10010. Проверка: 16 + 2 = 18.

Чётность числа видна по последнему биту. Чётность числа единиц определяется подсчётом всех единиц. У 10100 последний бит 0 и две единицы, а у 11100 последний бит тоже 0, но единиц три.

2. Дописываем справа

После дописывания k битов имеем R = 2k · N + значение хвоста. Хвост 01 занимает два разряда, поэтому множитель равен 4. Если дописать один бит 1, множитель равен 2.

Разбор · строгое неравенство

Чётному N добавляем 01, нечётному — 10. При N = 7 получаем 11110, то есть 30. При N = 8 получаем 33. Поэтому первое N с R > 30 — 8. Для N ≤ 7 результат не превышает 4 · 7 + 2 = 30.

3. Дописываем слева, удаляем или заменяем

Дописать 10 слева"10" + sПри длине исходной записи L имеем R = 2 · 2L + N.

Разбор · три команды для N = 13

В исходной записи 1101 четыре бита. Слева 10 даёт 101101 и R = 2 · 16 + 13 = 45. Удаление двух последних битов даёт 11 и R = 3. При замене последних двух на 10 получается 1110 и R = 14.

Чтобы после s[:-2] осталась хотя бы одна цифра, в примерах с удалением берём N ≥ 4. Если нужно использовать исходный последний бит после изменения строки, сохрани его заранее.

4. Пересчитываем после каждого шага

Разбор · N = 7

111 содержит три единицы, поэтому дописываем 1 и получаем 1111. Теперь единиц четыре, поэтому дописываем 0. В 11110 значение R равно 30. Второй бит чётности всегда 0: после первой дописки число единиц уже чётное.

5. Ищем N или R

Пусть хвосты 00, 10 и 100 соответствуют остаткам 0, 1 и 2 от деления N на 3. Длина хвоста меняется, поэтому R может уменьшиться при увеличении N.

Разбор · граница R > 50

При переборе N по возрастанию первым подходит N = 8, а минимальное подходящее R равно 54 при N = 13. Для N ≤ 4 можно проверить четыре строки отдельно (R = 6, 20, 12, 18). При всех N ≥ 14 имеем R ≥ 4N ≥ 56. Так мы доказали, что дальше меньшего подходящего R не будет.

Практика на Python

bin(n)[2:] берёт биты без 0b, s.count("1") считает единицы, int(s, 2) читает готовую строку как двоичное число. Сначала проверь функцию на двух входах вручную, затем запускай поиск.

def result(n):
    s = bin(n)[2:]
    tails = ("00", "10", "100")
    return int(s + tails[n % 3], 2)

# N = 13 даёт R = 54, а с N = 14 все R ≥ 56.
hits = []
for n in range(1, 14):
    r = result(n)
    if r > 50:
        hits.append((n, r))

first_n = hits[0][0]                 # N проверяли по возрастанию
best_n, best_r = min(hits, key=lambda pair: pair[1])
print(first_n, best_r)               # 8, 54
Откуда взять верхнюю границу

У дописывания справа R ≥ N. Если только удаляем два последних бита, R = N // 4, поэтому для условия R ≤ 20 достаточно проверить N до 83 включительно. С N = 84 результат уже не меньше 21. Если после удаления есть ещё команды, снова выведи нижнюю оценку R.

Для максимума N в конечном диапазоне можно идти с его верхнего конца. При поиске минимального R храни пары (N, R) и сравнивай их по второму числу. При пустом списке совпадений перепроверь условие и границу перебора.

Задачи парами

Разберите задачу А на доске. Затем ученик решает Б тем же приёмом и объясняет, что именно искал.

1. Дописываем два бита

К двоичной записи положительного N справа дописываем 01, если N чётное, и 10, если N нечётное. Из новой записи получаем число R.

А · Вместе. Найди наименьшее N с R > 35.

Б · Самостоятельно. Найди наименьшее N с R > 53.

2. Дважды пересчитываем единицы

Дважды подряд дописываем справа остаток от деления числа единиц в текущей записи на 2. После первого шага пересчитываем единицы. Из новой записи получаем число R.

А · Вместе. Найди наименьшее R, строго большее 40.

Б · Самостоятельно. Найди наименьшее R, строго большее 24.

3. Хвост зависит от остатка

Если N делится на 3, дописываем справа 00. Иначе дописываем двоичную запись удвоенного остатка от деления N на 3, без ведущих нулей. Из новой записи получаем число R.

А · Вместе. Найди наименьшее N с R > 45.

Б · Самостоятельно. Найди наименьшее R, строго большее 45.

4. Заменяем два последних бита

Для N ≥ 4 заменяем два последних бита двоичной записи на 10. Из новой записи получаем число R.

А · Вместе. Найди наименьшее N с R > 46.

Б · Самостоятельно. Найди наименьшее N с R > 66.

5. Удаляем биты и добавляем новый

Для N ≥ 4 удаляем два последних бита. К оставшейся записи справа дописываем 1, если исходное N чётное, и 0, если оно нечётное. Из новой записи получаем число R.

А · Вместе. Найди наименьшее N с R > 17.

Б · Самостоятельно. Найди наибольшее N с R < 23.

6. Дописываем слева

Для положительного N к его записи слева дописываем 10, если N чётное, и 1, если N нечётное. Из новой записи получаем число R.

А · Вместе. Найди наименьшее N с R > 24.

Б · Самостоятельно. Найди наименьшее R, строго большее 24.

С4Если в исходной двоичной записи положительного N чётное число единиц, допиши 1 слева. Если нечётное — допиши 01 справа. Найди наименьшее R, строго большее 30, и соответствующее N.

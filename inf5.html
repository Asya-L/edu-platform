Двоичные алгоритмы

Переводим число в двоичную строку, выполняем команды и ищем именно ту величину, которую спрашивают.

СлайдыРабочий листЗадачи парамиДомашкаСамопроверка
Три шага

Исходное число N → двоичная запись → изменения по условию → десятичное число R. Первые два шага удобно записывать отдельно: 6 и 110 — одно число, но разные записи.

Дописываем биты справа

Один новый бит умножает исходное число на 2 и добавляет значение этого бита. Если дописали k битов, получаем R = N · 2k + значение хвоста. Хвост 01 занимает два разряда, хотя его значение равно 1.

Пример вручную

Чётному N добавляем 01, нечётному — 10. При N = 7 получаем 11110, то есть 7 · 4 + 2 = 30. При N = 8 получаем 8 · 4 + 1 = 33. Поэтому первое N с R > 30 — 8: для N ≤ 7 результат не превышает 4 · 7 + 2.

Не путай наименьшее N и наименьшее R

При ветвлении длина дописанной строки может меняться. Тогда большее N не гарантирует большего R. Например, если дописывать 00 при остатке 0 от деления на 3, 10 при остатке 1 и 100 при остатке 2, то N = 5 даёт R = 44, а N = 6 даёт R = 24.

Перед запуском

Подчеркни искомое: N или R. При поиске первого подходящего N можно остановиться на первом совпадении. Для наименьшего R нужно сравнить результаты. «Строго больше» означает >, а не >=.

Перебор на Python

bin(n)[2:] возвращает биты без начала 0b; int(s, 2) читает двоичную строку как число.

def result(n):
    s = bin(n)[2:]
    r = n % 3
    suffix = "00" if r == 0 else bin(2 * r)[2:]
    return int(s + suffix, 2)

hits = [(n, result(n)) for n in range(1, 51)
        if result(n) > 50]

print(hits[0][0])                 # первое подходящее N
print(min(r for n, r in hits))    # наименьшее R

В примере с условием R > 50 можно проверить N от 1 до 50. Среди них есть результат 54. Для N > 50 дописывается хотя бы два бита, поэтому R ≥ 4N > 200: такой результат уже не может быть наименьшим. Для задачи с другим алгоритмом границу обосновывай заново.

Чётность после каждого шага

Если в записи нечётное число единиц, добавление 1 делает его чётным. Если число единиц уже чётное, добавляется 0. Поэтому второй бит в таком алгоритме всегда 0. Считай единицы в текущей строке, а не чётность N.

Задачи парами

Сначала разберите А вместе. Затем ученик решает Б тем же алгоритмом и объясняет, что именно искал.

1. Два бита и ветвление

Если N чётное, дописываем справа 01; если нечётное — 10. Получаем число R из новой записи.

А · Вместе. Найди наименьшее N, при котором R > 35.

Б · Самостоятельно. Найди наименьшее N, при котором R > 53.

2. Пересчёт единиц после дописки

Дважды подряд дописываем справа остаток от деления числа единиц в текущей записи на 2. Второй раз пересчитываем единицы после первой дописки. Получаем число R из новой записи.

А · Вместе. Найди наименьшее значение R, строго большее 40.

Б · Самостоятельно. Найди наименьшее значение R, строго большее 24.

3. Когда большие N не дают большие R

Если N делится на 3, дописываем справа 00. Иначе дописываем справа двоичную запись удвоенного остатка N от деления на 3, без ведущих нулей. Получаем число R из новой записи.

А · Вместе. Найди наименьшее N, при котором R > 45.

Б · Самостоятельно. Найди наименьшее значение R, строго большее 45.

Д5N — положительное целое число. Если N делится на 3, дописываем справа 00. Иначе дописываем справа двоичную запись удвоенного остатка N от деления на 3, без ведущих нулей. Полученную двоичную запись переводим в десятичное число R. Найди наименьшее значение R, строго большее 85. Ответ запиши в десятичной системе.

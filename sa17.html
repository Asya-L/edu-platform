§ 17

Десятичные и натуральные логарифмы

lg, ln и формула перехода

Обозначения

Два главных основания

lg b = log10 b:  lg 1000 = 3,  lg 0,01 = −2

ln b = loge b,  e ≈ 2,718:  ln e⁵ = 5,  eln 3 = 3

(1 + 1/n)ⁿ → e

n = 1: 2 · n = 10: ≈ 2,594 · n = 1000: ≈ 2,717

Формула перехода

Число — наверху, основание — внизу

Формулаloga b = logc b / logc a

log2 7 = lg 7 / lg 2 ≈ 0,8451 / 0,3010 ≈ 2,81

Следствия

Без калькулятора

  1. loga b = 1 / logb a
  2. logak b = (1/k)·loga b:  log√3 9 = 4
  3. loga b · logb c = loga c:  log3 5 · log5 9 = 2

Уравнение

3ˣ = 20

  1. x = log3 20 — точный ответ
  2. x = lg 20 / lg 3 ≈ 1,3010 / 0,4771

∛(2 − x) + √x − 1 = 1

  1. a = ∛(2 − x), b = √x − 1 ≥ 0
  2. a + b = 1, a³ + b² = 1
  3. b(b − 1)(b − 3) = 0
  4. x = 1, 2, 10

Приём 4

√x² + 9 − √x² − 7 = 2

  1. S = √x² + 9 + √x² − 7 ≥ 3 > 0 — умножать можно
  2. (x² + 9) − (x² − 7) = 2S ⇒ S = 8
  3. сложить с исходным: √x² + 9 = 5
  4. x = ±4, проверка: 5 − 3 = 2

Координаты вектора

Вектор — направленный отрезок: важно, откуда и куда он идёт. Координаты вектора показывают, на сколько нужно сместиться по x и по y, чтобы попасть из начала в конец. Из A(1; 2) в B(7; 10) — вправо на 7 − 1 = 6 и вверх на 10 − 2 = 8, поэтому AB = (6; 8). Отсюда правило «конец минус начало».

ЧтоФормула
Вектор AB по точкам A(x₁; y₁), B(x₂; y₂)AB = (x₂ − x₁; y₂ − y₁) — «конец минус начало»
Длина вектора a(x; y)|a| = √(x² + y²)
Сумма и разностьпокоординатно: a ± b = (x₁ ± x₂; y₁ ± y₂)
Умножение на числоk · a = (kx; ky), длина меняется в |k| раз
Пример 1

A(1; 2), B(7; 10). Найдите длину вектора AB.

Решение

AB = (7 − 1; 10 − 2) = (6; 8). Длина — по теореме Пифагора, смещения 6 и 8 — это катеты: |AB| = √(36 + 64) = 10.

Пример 2

a(3; −2), b(1; 4). Найдите абсциссу вектора 2a + b.

Решение

2a = (6; −4), 2a + b = (6 + 1; −4 + 4) = (7; 0). Абсцисса — первая координата: 7.

Будь внимателен

Координаты вектора — «конец минус начало», а не наоборот. Для BA знаки поменяются. На длину это не влияет, а на сумму векторов — влияет.

Скалярное произведение

Скалярное произведение векторов a и b — это число (не вектор), обозначается a · b. Оно связано с углом φ между векторами (векторы откладывают от одной точки). Его можно считать двумя способами:

Две формулы

1) Через координаты a(x₁; y₁), b(x₂; y₂): a · b = x₁x₂ + y₁y₂.

2) Через длины и угол: a · b = |a| · |b| · cos φ.

Приравняв их, находим угол: cos φ = (a · b) / (|a| · |b|).

Пример 3

a(2; 5), b(−4; 1). Найдите скалярное произведение.

Решение

Первая формула: 2 · (−4) + 5 · 1 = −8 + 5 = −3.

Пример 4

|a| = 4, |b| = 5, угол между векторами 60°. Найдите a · b.

Решение

Вторая формула, cos 60° = 0,5: 4 · 5 · 0,5 = 10.

Пример 5 · угол

a(3; 1), b(1; 2). Найдите угол между векторами.

Решение

a · b = 3 · 1 + 1 · 2 = 5; |a| = √(9 + 1) = √10, |b| = √(1 + 4) = √5.

cos φ = 5 / (√10 · √5) = 5/√50 = 5/(5√2) = 1/√2 = √2/2, поэтому φ = 45°.

Следствия (для ненулевых векторов):

  • a ⟂ b ⇔ a · b = 0 — потому что cos 90° = 0.
  • Если a · b > 0 — угол острый (cos φ > 0), если a · b < 0 — тупой.
  • a · a = |a|² (угол вектора с самим собой 0°, cos 0° = 1) — так находят длину суммы: |a + b|² = |a|² + 2a·b + |b|².
  • a ∥ b (векторы коллинеарны — лежат на одной или параллельных прямых) ⇔ координаты пропорциональны: x₁y₂ = x₂y₁; если у b нет нулевых координат, это то же, что x₁ / x₂ = y₁ / y₂. Например, a(2; −6) ∥ b(−1; 3): 2 · 3 = (−6) · (−1).
Пример 6

При каком k векторы a(k; 4) и b(2; −3) перпендикулярны?

Решение

Перпендикулярны ⇔ a · b = 0: k · 2 + 4 · (−3) = 2k − 12 = 0 → k = 6.

Пример 7 · длина суммы

|a| = 3, |b| = 5, угол между векторами 60°. Найдите |a + b|.

Решение

a · b = 3 · 5 · 0,5 = 7,5. |a + b|² = |a|² + 2a·b + |b|² = 9 + 15 + 25 = 49, значит |a + b| = 7.

В пространстве

Всё то же самое с третьей координатой: |a| = √(x² + y² + z²), a · b = x₁x₂ + y₁y₂ + z₁z₂.

Пример 8

a(1; 2; 2), b(2; −1; 3). Найдите a · b и |a|.

Решение

a · b = 2 − 2 + 6 = 6; |a| = √(1 + 4 + 4) = 3.

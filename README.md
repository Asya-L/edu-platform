# Кабинет математики

Материалы к занятиям по математике: https://asya-l.github.io/edu-platform/

Вход по почте и паролю (Supabase). Ученик видит конспекты, презентации, рабочие листы, справочник и ЕГЭ.
Учительская часть (`t/`) хранится зашифрованной; ключ выдаёт база только аккаунту с ролью «учитель».

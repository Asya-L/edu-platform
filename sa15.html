Логарифмы

В какую степень возвести основание?

Определение

Логарифм — показатель степени

Определениеloga b = c  ⇔  ac = b  (a > 0, a ≠ 1, b > 0)

2x = 5 ⇒ x = log2 5 — число между 2 и 3.

Задаём вопрос

  1. log2 8 = 3,  потому что 2³ = 8
  2. log3 (1/9) = −2,  потому что 3−2 = 1/9
  3. log27 9: 33c = 3² ⇒ c = 2/3

Уравнения

loga x = b ⇒ x = ab

  1. log3 x = 4 ⇒ x = 3⁴ = 81
  2. log2 (x − 1) = 3 ⇒ x − 1 = 8 ⇒ x = 9
  3. logx 16 = 2 ⇒ x² = 16, x > 0, x ≠ 1 ⇒ x = 4
  4. 5x = 7 ⇒ x = log5 7

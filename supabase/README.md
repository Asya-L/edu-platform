# Изменения действующей базы

Миграция `20261117103938_repair_student_resource_access.sql` применена 17.11.2026
к проекту кабинета. Это первая зафиксированная миграция; исходная схема существовала
до неё, поэтому этот каталог пока не позволяет развернуть пустую базу с нуля.

Для повторений используется закрытая функция `edu_private.owns_student(uuid)`:
она возвращает только принадлежность текущему пользователю, не открывая приватные
карточки учеников. Схему `edu_private` нельзя добавлять в Exposed schemas Data API.
Гость не имеет доступа к этой функции. Проверка файлов ДЗ использует существующую
`public.edu_owns_lesson`, которая проверяет ученика и факт отправки задания.

Проверка перед и после применения: `tests/student-access.sql`, 17 условий.
Миграция не меняет остальные таблицы, авторизацию приложения «12 недель»,
содержимое заданий или реальные файлы.

Миграция `20261117110859_atomic_board_operations.sql` добавляет ревизию доски,
закрытые метаданные повторных запросов и `edu_board_apply`. Применена после проверки
в транзакции; 20 SQL-регрессий и прежние 17 проверок доступа проходят в живой базе.
Подробности совместимости и хранения черновиков: `docs/board-persistence.md`.

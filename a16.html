Свойства логарифмов

§ 16 · логарифм произведения, частного и степени; вычисления и преобразования выражений

▶ Презентация Рабочий лист Домашнее задание

Теория

Свойства логарифмов — это свойства степеней, «переведённые» на язык показателей. Вспомним: при умножении степеней с одним основанием показатели складываются, при делении — вычитаются, при возведении в степень — умножаются. А логарифм и есть показатель. Поэтому и правил тоже три.

Свойства логарифмов

Пусть a > 0, a ≠ 1, b > 0, c > 0, p — любое число. Тогда

1) loga (bc) = loga b + loga c  — логарифм произведения;

2) loga (b/c) = loga b − loga c  — логарифм частного;

3) loga bp = p·loga b  — логарифм степени.

Доказательство

Докажем свойство 1. Обозначим loga b = m, loga c = n. По определению b = am, c = an. Тогда bc = am·an = am + n, и снова по определению loga (bc) = m + n.

Свойство 2 — так же: b/c = am − n. Свойство 3: bp = (am)p = apm, значит, loga bp = pm.

Проверим на числах: log2 (4·8) = log2 32 = 5, а log2 4 + log2 8 = 2 + 3 = 5 ✓.

Вычисления: «склеиваем» логарифмы

Часто каждый логарифм по отдельности не вычисляется, а их сумма или разность — легко. Тогда свойства читаем справа налево: сумму логарифмов превращаем в логарифм произведения, разность — в логарифм частного.

Пример 1

Вычисли: а) log6 4 + log6 9; б) log2 40 − log2 5.

Решение

а) log6 (4·9) = log6 36 = 2.

б) log2 (40/5) = log2 8 = 3.

Пример 2 · коэффициент перед логарифмом

Вычисли 2log3 6 − log3 4.

Решение

Коэффициент «заносим» в показатель по свойству 3: 2log3 6 = log3 6² = log3 36.

log3 36 − log3 4 = log3 (36/4) = log3 9 = 2.

Пример 3 · корни

Вычисли: а) log5 √5; б) log2 (8√2).

Решение

Корень — это степень с дробным показателем: √5 = 51/2.

а) log5 51/2 = (1/2)·log5 5 = 1/2.

б) log2 8 + log2 21/2 = 3 + 1/2 = 3,5.

Будь внимателен

Самая частая ошибка — придумать «свойство», которого нет:

loga (b + c) ≠ loga b + loga c  (например, log2 (4 + 4) = 3, а log2 4 + log2 4 = 4);

loga b : loga c ≠ loga (b/c);  (loga b)² ≠ 2loga b  (например, (log2 8)² = 9, а 2log2 8 = 6).

Свойства говорят только о логарифме произведения, частного и степени.

Преобразования: «раскладываем» логарифм

Теперь читаем свойства слева направо: логарифм сложного выражения раскладываем на сумму простых. Так удобно, когда известны логарифмы отдельных множителей.

Пример 4

Известно, что loga b = 2, loga c = 3. Найди: а) loga (b²c); б) loga (b³/c²).

Решение

а) loga b² + loga c = 2·2 + 3 = 7.

б) 3loga b − 2loga c = 6 − 6 = 0.

Пример 5 · найти число по его логарифму

Найди x, если log3 x = 2log3 5 − log3 10.

Решение

Соберём правую часть в один логарифм: 2log3 5 − log3 10 = log3 25 − log3 10 = log3 (25/10) = log3 2,5.

log3 x = log3 2,5, а равные логарифмы с одним основанием бывают только у равных чисел. Ответ: x = 2,5.

Будь внимателен

Все свойства верны только для положительных b и c. Например, log2 ((−2)·(−4)) = log2 8 = 3 существует, а записать его как log2 (−2) + log2 (−4) нельзя: таких логарифмов нет. Это важно в уравнениях — там можно потерять или приобрести корни.

§ 7 · обратимые функции, взаимно обратные функции, симметрия графиков относительно y = x

▶ Презентация Рабочий лист Домашнее задание

Теория

Обратимая функция

Функция по каждому x находит y. А можно ли «повернуть назад» — по значению y однозначно узнать, из какого x оно получилось? Для y = 2x + 1 можно: y = 7 только при x = 3. Для y = x² нельзя: y = 4 и при x = 2, и при x = −2.

Определение

Функцию y = f(x) называют обратимой, если для любого y₀ ∈ E(f) существует единственное x₀ ∈ D(f), такое, что y₀ = f(x₀).

Иначе говоря, обратимая функция каждое своё значение принимает ровно один раз. На графике это видно сразу: любая горизонтальная прямая пересекает график обратимой функции не более чем в одной точке.

Теорема 7.1

Если функция возрастающая (убывающая), то она обратима.

Доказательство

Пусть y = f(x) возрастает, а какое-то значение принимается дважды: f(x₁) = f(x₂), где x₁ < x₂. Но для возрастающей функции из x₁ < x₂ следует f(x₁) < f(x₂) — противоречие. Для убывающей — так же.

Обратная теорема неверна: обратимая функция не обязана быть монотонной. Пример — y = 1/x: каждое значение она принимает один раз, но на всей области определения не возрастает и не убывает (−1 < 1, а 1/(−1) = −1 < 1/1 = 1, хотя на каждом промежутке функция убывает).

Взаимно обратные функции

Пусть функция f задана таблицей: f(5) = √5, f(6) = √6, f(7) = √7. Поменяем строки таблицы местами — получим функцию g: g(√5) = 5, g(√6) = 6, g(√7) = 7. Функция g «отменяет» действие f: g(f(x)) = x.

Определение

Функции f и g называют взаимно обратными, если: 1) D(f) = E(g) и E(f) = D(g); 2) для любого x₀ ∈ D(f) из f(x₀) = y₀ следует g(y₀) = x₀, то есть g(f(x₀)) = x₀.

Говорят, что g — функция, обратная к f. Обратная функция есть только у обратимой функции, и у каждой обратимой она есть.

Как найти обратную функцию

  1. Убедиться, что функция обратима (например, монотонна) — при необходимости сузить область определения.
  2. Выразить x через y из равенства y = f(x).
  3. Поменять обозначения: аргумент снова назвать x, значение — y.
  4. Записать область определения обратной функции: D(g) = E(f).
Пример 1 · линейная функция

Найди функцию, обратную к y = 2x + 1.

Решение

Функция возрастает — значит, обратима. Выражаем x: 2x = y − 1, x = (y − 1)/2. Меняем обозначения: y = (x − 1)/2.

Проверка: g(f(x)) = ((2x + 1) − 1)/2 = x. Верно.

Пример 2 · дробь

Найди функцию, обратную к y = 1/(x − 2).

Решение

D(f): x ≠ 2; E(f): y ≠ 0 (дробь с числителем 1 нулю не равна). Каждое значение принимается один раз: из 1/(x − 2) = y₀ однозначно x = 2 + 1/y₀.

Меняем обозначения: y = 2 + 1/x, x ≠ 0. Её область значений y ≠ 2 — совпадает с D(f), как и требует определение.

Пример 3 · сужаем область определения

Найди функцию, обратную к y = x² − 1, x ≥ 0.

Решение

На всей прямой x² − 1 не обратима, а на [0; +∞) она возрастает — обратима. E(f) = [−1; +∞).

x² = y + 1, и так как x ≥ 0, то x = √(y + 1) (не «±»!). Ответ: y = √(x + 1), D = [−1; +∞).

Будь внимателен

При извлечении корня смотри на ограничение x ≥ 0 или x ≤ 0. Для y = x², x ≤ 0, обратная — y = −√x, а не √x.

Графики взаимно обратных функций

Теорема 7.2

Графики взаимно обратных функций симметричны относительно прямой y = x.

Почему: если точка M(a; b) лежит на графике f, то f(a) = b, значит, g(b) = a, и точка N(b; a) лежит на графике g. А точки (a; b) и (b; a) симметричны относительно прямой y = x: эта прямая — серединный перпендикуляр отрезка MN.

Теоремы 7.3 и 7.4

Если f возрастает (убывает), то и обратная функция g возрастает (убывает). Общие точки графиков возрастающих взаимно обратных функций лежат на прямой y = x. Поэтому уравнение f(x) = g(x) для них равносильно уравнению f(x) = x.

Пример 4 · уравнение

Реши уравнение √(√x + 2) = x − 2.

Решение

Заменим √x = t, t ≥ 0; тогда x = t², и уравнение принимает вид √(t + 2) = t² − 2.

Функции f(t) = t² − 2 на [0; +∞) и g(t) = √(t + 2) взаимно обратные (проверь: из y = t² − 2, t ≥ 0, получаем t = √(y + 2)) и обе возрастают. Значит, уравнение равносильно t² − 2 = t, то есть t² − t − 2 = 0, t = 2 или t = −1. Условию t ≥ 0 отвечает t = 2.

√x = 2, x = 4. Проверка: √(√4 + 2) = √4 = 2 и 4 − 2 = 2.

Будь внимателен

Теорема 7.4 требует возрастания. Функция y = −x обратна сама себе и убывает: графики f и g здесь совпадают, и их общие точки, например (1; −1), не лежат на прямой y = x.

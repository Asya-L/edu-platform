Теория

Что такое множество

В жизни мы постоянно объединяем предметы в группы по какому-то признаку: ученики твоего класса, книги на полке, дни недели. В математике для любой такой «группы» есть одно слово — множество. Предметы, из которых оно состоит, называют его элементами. Множества обычно обозначают большими латинскими буквами: A, B, C.

Если элемент a принадлежит множеству A, пишут a ∈ A (читают: «a принадлежит A»). Если не принадлежит — a ∉ A. Например, 3 ∈ {1, 2, 3}, а 5 ∉ {1, 2, 3}.

Некоторые множества встречаются так часто, что у них есть постоянные имена:

  • N — натуральные числа 1, 2, 3, …;
  • Z — целые числа …, −2, −1, 0, 1, 2, …;
  • Q — рациональные числа, то есть дроби m/n, где m ∈ Z, n ∈ N;
  • R — все действительные числа, вся числовая прямая.
Будь внимателен

В нашем учебнике натуральные числа начинаются с единицы: 0 ∉ N, но 0 ∈ Z. Если в задаче нужно «натуральное или ноль», так и пишут: n ∈ N или n = 0.

Как задать множество

Первый способ — перечислить все элементы в фигурных скобках: M = {1, 2, 3, 4} — натуральные числа, меньшие 5. Порядок элементов и повторы роли не играют: {1, 2} и {2, 1} — одно и то же множество.

Второй способ — указать характеристическое свойство: такое свойство, которым обладают все элементы множества и только они. Записывают так: {x | условие на x}. Вертикальная черта читается «таких, что». Например:

  • {x | x = 3n, n ∈ N} — натуральные числа, кратные 3, то есть {3, 6, 9, …};
  • {x | x² − 4 = 0} — корни уравнения x² = 4, то есть {−2, 2}.

Второй способ незаменим, когда элементов бесконечно много: все числа, кратные 3, не перечислишь.

Множество, в котором нет ни одного элемента, называют пустым и обозначают ∅. Например, {x | x ∈ R, x² = −1} = ∅: квадрат действительного числа не бывает отрицательным.

Подмножество

Определение

Множество B называют подмножеством множества A, если каждый элемент B является элементом A. Пишут: B ⊂ A (или A ⊃ B).

Такие картинки — круги, изображающие множества, — называют диаграммами Эйлера. Числовые множества вложены друг в друга: N ⊂ Z ⊂ Q ⊂ R.

Несколько фактов, которые прямо следуют из определения:

  • ∅ ⊂ A для любого A: в пустом множестве нет элементов, значит, нет и «лишних»;
  • A ⊂ A: каждый элемент A лежит в A;
  • если A ⊂ B и B ⊂ A, то A = B — так обычно и доказывают равенство множеств.
Определение

Если B ⊂ A и B ≠ A, то B называют собственным подмножеством A. Например, Z — собственное подмножество Q.

Будь внимателен

Не путай знаки ∈ и ⊂. Знак ∈ ставят между элементом и множеством, знак ⊂ — между двумя множествами. Верно: a ∈ {a, b} и {a} ⊂ {a, b}. Неверно: {a} ∈ {a, b} и a ⊂ {a, b}.

Пример 1 · все подмножества

Назови все подмножества множества {a, b, c}.

Решение

Перебираем по числу элементов, чтобы ничего не потерять:

  • 0 элементов: ∅;
  • 1 элемент: {a}, {b}, {c};
  • 2 элемента: {a, b}, {a, c}, {b, c};
  • 3 элемента: {a, b, c}.

Всего 8 подмножеств, из них 7 собственных (все, кроме самого множества).

Пересечение и объединение

Определение

Пересечением множеств A и B называют множество, состоящее из всех элементов, принадлежащих и A, и B. Обозначение: A ∩ B = {x | x ∈ A и x ∈ B}.

Определение

Объединением множеств A и B называют множество, состоящее из всех элементов, принадлежащих хотя бы одному из них: или A, или B. Обозначение: A ∪ B = {x | x ∈ A или x ∈ B}.

Запомнить легко: ∩ — «и», нужно быть в обоих; ∪ — «или», достаточно быть хотя бы в одном. Общий элемент в объединение записывают один раз.

  • если у A и B нет общих элементов, то A ∩ B = ∅;
  • A ∩ ∅ = ∅,   A ∪ ∅ = A;
  • если A ⊂ B, то A ∩ B = A и A ∪ B = B (например, Q ∩ N = N).

Так же определяют пересечение и объединение трёх и более множеств: в пересечение входят элементы, лежащие во всех множествах, в объединение — лежащие хотя бы в одном. Например, объединение множеств остроугольных, прямоугольных и тупоугольных треугольников — это все треугольники.

Разность и дополнение

Определение

Разностью множеств A и B называют множество всех элементов, которые принадлежат A, но не принадлежат B. Обозначение: A \ B = {x | x ∈ A и x ∉ B}.

Из A «вычёркиваем» всё, что есть в B. Поэтому A \ ∅ = A, а если A ⊂ B, то A \ B = ∅. Например, Z \ N = {0, −1, −2, …} — целые неположительные числа.

Если B ⊂ A, разность A \ B называют дополнением множества B в множестве A. Дополнение нечётных чисел в N — чётные числа.

Будь внимателен

Разность не «симметрична»: A \ B и B \ A — обычно разные множества. Для {1, 2, 3} и {3, 4}: {1, 2, 3} \ {3, 4} = {1, 2}, а {3, 4} \ {1, 2, 3} = {4}.

Разбор примеров

Пример 2 · конечные множества

A — множество натуральных делителей числа 12, B — делителей числа 18. Найди A ∩ B, A ∪ B, A \ B и B \ A.

Решение

Сначала перечислим элементы: A = {1, 2, 3, 4, 6, 12}, B = {1, 2, 3, 6, 9, 18}.

  • общие элементы: A ∩ B = {1, 2, 3, 6} — это делители числа 6 = НОД(12, 18);
  • все вместе, без повторов: A ∪ B = {1, 2, 3, 4, 6, 9, 12, 18};
  • из A убираем элементы B: A \ B = {4, 12};
  • из B убираем элементы A: B \ A = {9, 18}.
Пример 3 · промежутки

A = [−2; 5), B = (1; 7]. Найди A ∩ B, A ∪ B и A \ B.

Решение

Изобразим оба промежутка на числовых прямых одну под другой. Квадратная скобка — конец входит (закрашенная точка), круглая — не входит (выколотая).

Пересечение — там, где штриховки накладываются: от 1 (не входит в B) до 5 (не входит в A): A ∩ B = (1; 5).

Объединение — всё заштрихованное: A ∪ B = [−2; 7].

Разность — точки A, не попавшие в B: от −2 до 1, причём 1 ∉ B, значит, 1 остаётся: A \ B = [−2; 1].

Будь внимателен

На концах промежутков проверяй каждую точку отдельно: «входит ли она в первое множество? во второе?». Самая частая ошибка — потерять или лишний раз взять конец, как точку 1 в A \ B.

Пример 4 · множества, заданные свойством

A = {x | x = 4n, n ∈ N}, B = {x | x = 6n, n ∈ N}. Найди A ∩ B.

Решение

A — натуральные числа, кратные 4; B — кратные 6. В пересечение входят числа, кратные и 4, и 6, то есть кратные их наименьшему общему кратному НОК(4, 6) = 12.

Ответ: A ∩ B = {x | x = 12n, n ∈ N} = {12, 24, 36, …}.

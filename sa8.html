Равносильные уравнения и неравенства

Откуда берутся лишние корни и куда пропадают нужные

Загадка

Где ошибка?

x/(x − 2) = 2/(x − 2) ⇒ x = 2.

Но при x = 2 знаменатель равен нулю! Корней нет.

Определение

Равносильные уравнения

ОпределениеИмеют одни и те же корни (или оба не имеют корней).

2x − 6 = 0 ⇔ x = 3  ·  x² = 9 и x = 3 — не равносильны

Можно

Равносильные преобразования

  1. Перенос слагаемого с противоположным знаком
  2. Умножение и деление на число ≠ 0
  3. Тождественные преобразования без изменения ОДЗ

Осторожно

Посторонние корни

  1. Возведение в квадрат: √(x + 2) = x ⇒ x = 2 или −1; проверка оставляет 2
  2. Умножение на знаменатель — расширение ОДЗ

После таких шагов — проверка обязательна.

Нельзя

Потеря корня

Ошибкаx(x − 2) = 3(x − 2)  :  (x − 2) ⇒ x = 3 — потерян корень x = 2

Правильно: (x − 2)(x − 3) = 0 ⇒ x = 2 или x = 3

Часть 2

Неравенства

Знак меняется при умножении на отрицательное

Метод интервалов

(x − 1)/(x + 2) > 0

  1. Нули: x = 1 и x = −2 (выколотые)
  2. Знаки: +, −, +
  3. Ответ: (−∞; −2) ∪ (1; +∞)

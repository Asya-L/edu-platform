§ 22

y = tg x и y = ctg x

Тангенсоида и котангенсоида

Тангенс

y = tg x

  1. D: x ≠ π/2 + πn
  2. E = R, период π
  3. возрастает на каждом интервале
  4. асимптоты x = π/2 + πn

Котангенс

y = ctg x

  1. D: x ≠ πn
  2. E = R, период π
  3. убывает на каждом интервале
  4. нули π/2 + πn

Осторожно

Монотонность — по интервалам

Важноπ/4 < 3π/4, но tg π/4 = 1 > tg 3π/4 = −1: сравнивать можно только внутри одного интервала.

tg 1 < tg 1,5  ·  tg 130° < tg 150°  ·  ctg 2 > ctg 3

Пример

y = |ctg x| · tg x

x ≠ πn/2; значение равно знаку ctg x: 1 или −1.

Алгебра · § 12

Свойства корня n-й степени

§ 12 · корень из степени, произведения и частного, степень корня, корень из корня; преобразования

▶ Презентация Рабочий лист Домашнее задание

Теория

Все свойства этого урока доказываются одним приёмом. Чтобы проверить, что n√x = y, достаточно убедиться, что yn = x (а для чётного n — ещё и что y ≥ 0). Запомни этот приём: так ты сможешь «восстановить» любую формулу, если забудешь её.

Теорема 12.1 · корень из степени

Для любого a и k ∈ N:   2k+1√a2k+1 = a,   2k√a2k = |a|.

Почему во втором случае модуль? Корень чётной степени — неотрицательное число, а a может быть отрицательным. Число |a| неотрицательно и (|a|)2k = a2k — значит, это и есть корень. Например, 4√(−3)⁴ = 3.

Будь внимателен

4√a⁴ = |a|, а не a. Ошибка «4√(−3)⁴ = −3» — самая частая на этом уроке: корень чётной степени отрицательным не бывает.

Теорема 12.2 · корень из произведения

Если a ≥ 0 и b ≥ 0, то n√(ab) = n√a · n√b.

Доказательство

n√a · n√b ≥ 0 и (n√a · n√b)n = (n√a)n · (n√b)n = ab.

Если a ≤ 0 и b ≤ 0, то n√(ab) = n√(−a) · n√(−b). Для нечётного n формула верна при любых a и b.

Теорема 12.3 · корень из частного

Если a ≥ 0 и b > 0, то n√(a/b) = n√a / n√b.

Теорема 12.4 · степень корня

Если a ≥ 0, то (n√a)k = n√ak.

Теорема 12.5 · корень из корня

Если a ≥ 0, то k√(n√a) = nk√a.

Доказательство

n√a ≥ 0, значит, и левая часть ≥ 0; а (k√(n√a))nk = ((k√(n√a))k)n = (n√a)n = a.

Теорема 12.6 · сокращение показателей

Если a ≥ 0, то nk√ak = n√a. Например, 6√27² = 3√27 = 3.

Разбор примеров

Пример 1 · вычислить

Вычисли: 3√16 · 3√4; 4√2 · 4√8; 5√96 : 5√3; 4√(5⁴ · 3⁸).

Решение

3√(16 · 4) = 3√64 = 4; 4√16 = 2; 5√32 = 2; 4√5⁴ · 4√(3²)⁴ = 5 · 9 = 45.

Пример 2 · модули

Упрости: а) 6√a⁶ при a < 0; б) 3√a³; в) 4√(x⁴y⁸) при x < 0.

Решение

а) 6√a⁶ = |a| = −a (при a < 0 это положительное число!). б) Степень нечётная: a. в) 4√(xy²)⁴ = |xy²| = |x| · y² = −xy².

Пример 3 · вынести множитель

Вынеси множитель из-под знака корня: 3√54; 4√162; 4√a⁵.

Решение

3√(27 · 2) = 33√2; 4√(81 · 2) = 34√2; в 4√a⁵ обязательно a ≥ 0 (иначе корень не существует), поэтому 4√(a⁴ · a) = a4√a.

Пример 4 · внести множитель

Внеси множитель под знак корня: 23√3; a4√2.

Решение

23√3 = 3√(8 · 3) = 3√24 (для нечётной степени знак множителя не важен).

a4√2: если a ≥ 0, то 4√(2a⁴); если a < 0, то значение отрицательно, и пишут −4√(2a⁴).

Будь внимателен

Под корень чётной степени можно вносить только неотрицательный множитель. Отрицательный множитель оставляют снаружи знаком «минус».

Пример 5 · сократить дробь

Сократи дробь (√a − √b) / (4√a − 4√b).

Решение

√a = (4√a)², √b = (4√b)². Числитель — разность квадратов: (4√a − 4√b)(4√a + 4√b). Ответ: 4√a + 4√b.

Пример 6 · вложенные корни

Докажи, что 3√(5 + 2√13) + 3√(5 − 2√13) = 1.

Решение

Обозначим сумму через x и возведём в куб по формуле (p + q)³ = p³ + q³ + 3pq(p + q):

x³ = 10 + 3 · 3√(25 − 52) · x = 10 − 9x.

x³ + 9x − 10 = 0, (x − 1)(x² + x + 10) = 0. У второй скобки нет корней, значит, x = 1.

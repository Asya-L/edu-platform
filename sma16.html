Пример

√x + 2 и x

  1. √x + 2 < x ⇒ (2; +∞)
  2. √x + 2 > x ⇒ [−2; 0) ∪ [0; 2) = [−2; 2)

Нестрогое

√x² − x − 6 ≥ x − 2

  1. x < 2 и корень существует: x ≤ −2
  2. x ≥ 2: 3x ≥ 10, x ≥ 103
  3. Ответ: (−∞; −2] ∪ [103; +∞)

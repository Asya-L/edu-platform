Что такое параметр

Параметр (обычно буква a) — это число, которое не названо заранее. На время решения считаем его известным и смотрим, как ответ зависит от a. Пример: уравнение x² = a. При a < 0 корней нет (квадрат не бывает отрицательным); при a = 0 один корень x = 0; при a > 0 два корня x = ±√a.

Вопрос задания 19 обычно звучит так: «при каких a уравнение (или система) имеет ровно столько-то решений?» Ответ — не число, а множество значений a: промежуток, объединение промежутков или отдельные точки.

Аналитический метод

Коэффициенты квадратного уравнения обозначим большими буквами, чтобы не путать с параметром a: Ax² + Bx + C = 0, A ≠ 0, D = B² − 4AC.

ВопросУсловие для Ax² + Bx + C = 0, A ≠ 0
Два различных корняD > 0
Один кореньD = 0 (и отдельно проверить случай, когда коэффициент при x² равен 0!)
Корни одного знакаD ≥ 0 и x₁x₂ = C/A > 0
Оба положительныD > 0, x₁ + x₂ > 0, x₁x₂ > 0
Корни разных знаковC/A < 0 (D проверять не нужно)

Откуда эти условия: по теореме Виета x₁ + x₂ = −B/A, x₁x₂ = C/A. Если произведение положительно, корни одного знака; если вдобавок сумма положительна — оба положительны. Если C/A < 0, то AC < 0 и D = B² − 4AC > 0 автоматически — поэтому в последней строке D проверять не нужно.

Пример 1

При каких a уравнение x² + 2(a − 1)x + a + 5 = 0 имеет два различных положительных корня?

Решение

Коэффициент при x² равен 1, уравнение точно квадратное. B = 2(a − 1) — чётный, поэтому удобно считать D/4 = (B/2)² − AC (знак у D/4 тот же, что у D).

1) Два различных корня: D/4 = (a − 1)² − (a + 5) = a² − 3a − 4 = (a + 1)(a − 4) > 0 → a < −1 или a > 4.

2) Сумма корней −2(a − 1) > 0 → a < 1. 3) Произведение a + 5 > 0 → a > −5.

Все три условия вместе: −5 < a < −1. Ответ: (−5; −1).

Будь внимателен

Если коэффициент при x² содержит параметр, при его нуле уравнение становится линейным — этот случай рассматривают отдельно. Например, (a − 1)x² + 2x + 1 = 0 при a = 1 превращается в 2x + 1 = 0 с одним корнем x = −1/2, хотя дискриминант здесь вообще неприменим. Этот случай пропускают чаще всего.

Графический метод

Уравнение f(x) = a: число его корней равно числу точек пересечения графика y = f(x) с горизонтальной прямой y = a. Рисуем график один раз и «двигаем» прямую вверх-вниз. Поэтому полезно начинать с вопроса: можно ли записать уравнение в виде a = f(x)? Если да — графический метод обычно самый быстрый.

Пример 2

При каких a уравнение |x² − 4x| = a имеет ровно три корня?

Решение

Шаг 1. Парабола y = x² − 4x пересекает ось Ox в точках 0 и 4, вершина (2; −4). Модуль отражает часть ниже оси вверх — получается «горб» с вершиной (2; 4).

Шаг 2. Двигаем прямую y = a: a < 0 — нет пересечений (0 корней); a = 0 — 2 точки (x = 0 и 4); 0 < a < 4 — 4 точки; a = 4 — 3 точки (вершина горба и две по краям); a > 4 — 2 точки.

Шаг 3. Ровно три корня — только при a = 4.

Пример 3

При каких a уравнение (x − a)(x² − 5x + 6) = 0 имеет ровно два различных корня?

Решение

Произведение равно нулю, когда x = a или x² − 5x + 6 = 0, то есть x = 2 или x = 3. Если a ≠ 2 и a ≠ 3, различных корней три: 2, 3 и a. Если a = 2 или a = 3, корень x = a совпадает с одним из них, и различных корней остаётся два. Ответ: a ∈ {2; 3}.

Аналитический метод

ВопросУсловие для ax² + bx + c = 0, a ≠ 0
Два различных корняD > 0
Один кореньD = 0 (и отдельно проверить случай a = 0!)
Корни одного знакаD ≥ 0 и x₁x₂ = c/a > 0
Оба положительныD > 0, x₁ + x₂ > 0, x₁x₂ > 0
Корни разных знаковc/a < 0 (D проверять не нужно)
Пример 1

При каких a уравнение x² + 2(a − 1)x + a + 5 = 0 имеет два различных положительных корня?

Решение

D/4 = (a − 1)² − (a + 5) = a² − 3a − 4 > 0 → a < −1 или a > 4. Сумма −2(a − 1) > 0 → a < 1. Произведение a + 5 > 0 → a > −5. Ответ: (−5; −1).

Будь внимателен

Если коэффициент при x² содержит параметр, при его нуле уравнение становится линейным — этот случай рассматривают отдельно. Это самая частая потеря баллов.

Графический метод

Уравнение f(x) = a: число его корней равно числу точек пересечения графика y = f(x) с горизонтальной прямой y = a. Рисуем график один раз и «двигаем» прямую.

Пример 2

При каких a уравнение |x² − 4x| = a имеет ровно три корня?

Решение

График y = |x² − 4x|: парабола, часть между корнями 0 и 4 отражена вверх; «горб» с вершиной (2; 4). Прямая y = a даёт: a < 0 — 0 корней; a = 0 — 2; 0 < a < 4 — 4; a = 4 — 3; a > 4 — 2. Ответ: a = 4.

Пример 3

При каких a уравнение (x − a)(x² − 5x + 6) = 0 имеет ровно два различных корня?

Решение

Корни 2, 3 и a. Два различных — когда a совпадает с 2 или 3. Ответ: a ∈ {2; 3}.

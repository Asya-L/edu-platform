Будь внимателен

Если |a| > 1, уравнения sin x = a и cos x = a корней не имеют — это частый «отброшенный корень» после замены.

Методы

  • Замена: 2sin²x − 3sin x + 1 = 0 → t = sin x, |t| ≤ 1; 4ˣ − 5 · 2ˣ + 4 = 0 → t = 2ˣ, t > 0.
  • Формулы: cos 2x = 1 − 2sin²x = 2cos²x − 1; sin 2x = 2 sin x cos x; sin²x + cos²x = 1.
  • Разложение на множители: произведение равно нулю ⇔ хотя бы один множитель равен нулю (и выражение имеет смысл). Делить на выражение с переменной нельзя — потеряете корни.
Пример 1

а) Решите уравнение 2sin²x − 3sin x + 1 = 0. б) Найдите его корни на отрезке [−2π; −π/2].

Решение

а) t = sin x: 2t² − 3t + 1 = 0 → t = 1 или t = 1/2. sin x = 1 → x = π/2 + 2πk; sin x = 1/2 → x = π/6 + 2πk, x = 5π/6 + 2πk.

б) k = −1: −3π/2, −11π/6, −7π/6 — все в отрезке; при других k корни вне отрезка. Ответ: а) π/2 + 2πk, π/6 + 2πk, 5π/6 + 2πk, k ∈ ℤ; б) −11π/6, −3π/2, −7π/6.

Пример 2

а) Решите уравнение sin 2x = √3 cos x. б) Найдите корни на отрезке [−π; π/2].

Решение

а) 2 sin x cos x − √3 cos x = 0 → cos x (2 sin x − √3) = 0. cos x = 0 → x = π/2 + πk; sin x = √3/2 → x = π/3 + 2πk, 2π/3 + 2πk.

б) −π/2, π/3, π/2. Ответ: а) π/2 + πk, π/3 + 2πk, 2π/3 + 2πk; б) −π/2; π/3; π/2.

Будь внимателен

В примере 2 нельзя делить обе части на cos x — потеряется серия x = π/2 + πk.

Отбор корней

  1. Перебор k: подставляем k = …, −1, 0, 1, … пока корни не выйдут за отрезок.
  2. Двойное неравенство: a ≤ x₀ + 2πk ≤ b → находим целые k.
  3. Окружность: отмечаем дугу отрезка и точки серий — видно, какие попадают.

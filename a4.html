Арифметический корень натуральной степени

§ 4 · корень n-й степени, его свойства и уравнение xⁿ = a

▶ Презентация Рабочий лист Домашнее задание

Теория

Что такое корень n-й степени

Квадратный корень из 9 — это неотрицательное число, квадрат которого равен 9, то есть 3. Точно так же можно спрашивать: какое число в кубе даёт 8? в четвёртой степени даёт 81? Так появляется корень n-й степени.

Определение

Арифметическим корнем натуральной степени n ≥ 2 из неотрицательного числа a называется неотрицательное число, n-я степень которого равна a. Обозначение: n√a.

Примеры: ³√8 = 2, так как 2³ = 8; ⁴√81 = 3, так как 3⁴ = 81; ⁵√0 = 0.

Корень нечётной степени из отрицательного числа

Куб отрицательного числа отрицателен: (−2)³ = −8. Поэтому для нечётных n корень определяют и из отрицательных чисел: ³√(−8) = −2, ⁵√(−32) = −2. Общее правило: 2k+1√(−a) = −2k+1√a.

Будь внимателен

Корень чётной степени из отрицательного числа не существует (среди действительных чисел): ⁴√(−16) — бессмысленная запись, ведь любое число в четвёртой степени неотрицательно. Частая ошибка — написать ⁴√(−16) = −2.

Уравнение xⁿ = a

Пример 1

Решить уравнения: а) x⁴ = 81; б) x³ = −27; в) x⁶ = −1.

Решение

а) x = ±3; б) x = −3; в) корней нет (чётная степень не бывает отрицательной).

Свойства корня

Для a ≥ 0, b > 0 и натуральных n, m, k ≥ 2 (в последнем свойстве k — любое натуральное):

  1. n√(ab) = n√a · n√b
  2. n√(a/b) = n√a / n√b
  3. (n√a)m = n√(am)
  4. m√(n√a) = mn√a
  5. nk√(amk) = n√(am) (основное свойство: можно сокращать показатели)
Пример 2

Вычислить ³√(8 · 27) и ⁴√(16/81).

Решение

³√8 · ³√27 = 2 · 3 = 6; ⁴√16 / ⁴√81 = 2/3.

Пример 3

Вычислить ³√4 · ³√16 и ⁵√96 / ⁵√3.

Решение

³√64 = 4; ⁵√32 = 2. Сначала объединяем под одним корнем, потом извлекаем.

Пример 4

Упростить ³√(√64) и ⁶√(7³)².

Решение

⁶√64 = 2; ⁶√7⁶ = 7.

Корень чётной степени из степени

Правило

n√(an) = |a| при чётном n;   n√(an) = a при нечётном n

Пример 5

Вычислить ⁴√((−3)⁴) и ³√((−3)³).

Решение

⁴√81 = 3 = |−3|; ³√(−27) = −3.

Будь внимателен

Частая ошибка: ⁴√((−3)⁴) = −3. Корень чётной степени всегда неотрицателен, поэтому нужен модуль.

Арифметический корень натуральной степени

§ 4 · корень n-й степени, его свойства и уравнение xⁿ = a

▶ Презентация Рабочий лист Домашнее задание

Теория

Что такое корень n-й степени

Квадратный корень из 9 — это неотрицательное число, квадрат которого равен 9, то есть 3. Точно так же можно спрашивать: какое число в кубе даёт 8? в четвёртой степени даёт 81? Так появляется корень n-й степени.

Определение

Арифметическим корнем натуральной степени n ≥ 2 из неотрицательного числа a называется неотрицательное число, n-я степень которого равна a. Обозначение: n√a.

Примеры: ³√8 = 2, так как 2³ = 8; ⁴√81 = 3, так как 3⁴ = 81; ⁵√0 = 0.

Как читать и называть: n√a — «корень n-й степени из a», число n — показатель корня, a — подкоренное выражение. Корень 3-й степени называют кубическим. При n = 2 показатель не пишут: √a — это знакомый квадратный корень. Слово «арифметический» напоминает: сам корень всегда неотрицателен.

Корень нечётной степени из отрицательного числа

Куб отрицательного числа отрицателен: (−2)³ = −8. Поэтому для нечётных n корень определяют и из отрицательных чисел: ³√−8 = −2, ⁵√−32 = −2. Общее правило: 2k+1√−a = −2k+1√a.

Будь внимателен

Корень чётной степени из отрицательного числа не существует (среди действительных чисел): ⁴√−16 — бессмысленная запись, ведь любое число в четвёртой степени неотрицательно. Частая ошибка — написать ⁴√−16 = −2.

Уравнение xⁿ = a

Начнём с примера: x⁴ = 81. Подходит x = 3, но и x = −3 тоже: (−3)⁴ = 81, потому что чётная степень «съедает» минус. А в уравнении x³ = 27 подходит только 3: (−3)³ = −27. Отсюда общая картина:

n нечётноеодин корень n√ax = 0один корень −n√|a|
Пример 1

Решить уравнения: а) x⁴ = 81; б) x³ = −27; в) x⁶ = −1.

Решение

а) Степень чётная, 81 > 0 — два корня: x = ±⁴√81 = ±3. б) Степень нечётная — один корень: x = −³√27 = −3 (проверка: (−3)³ = −27). в) Чётная степень не бывает отрицательной — корней нет.

Свойства корня

Пусть a ≥ 0, b > 0, а n, m, k — натуральные числа; там, где число стоит показателем корня, оно не меньше 2. Тогда:

  1. n√ab = n√a · n√b
  2. n√ab = n√a / n√b
  3. (n√a)m = n√am
  4. m√n√a = mn√a
  5. nk√amk = n√am (основное свойство: можно сокращать показатели)

Откуда берутся свойства — покажем на первом. Число ⁿ√a · ⁿ√b неотрицательно (произведение неотрицательных чисел). Возведём его в n-ю степень: (ⁿ√a · ⁿ√b)n = (ⁿ√a)n · (ⁿ√b)n = a · b. Значит, по определению это и есть ⁿ√ab. Остальные свойства проверяются так же: обе части неотрицательны, а их n-е степени равны.

Пример 2

Вычислить ³√8 · 27 и ⁴√1681.

Решение

³√8 · ³√27 = 2 · 3 = 6; ⁴√16 / ⁴√81 = 2/3.

Будь внимателен

Корень из суммы не равен сумме корней: свойства есть только для произведения и частного. Проверь на числах: √9 + 16 = √25 = 5, а √9 + √16 = 3 + 4 = 7.

Пример 3

Вычислить ³√4 · ³√16 и ⁵√96 / ⁵√3.

Решение

³√64 = 4; ⁵√32 = 2. Сначала объединяем под одним корнем, потом извлекаем.

Пример 4

Упростить ³√√64 и ⁶√7³².

Решение

³√√64 = ⁶√64 = 2 (свойство 4: показатели корней перемножаются, 3 · 2 = 6; и правда, 2⁶ = 64).

(⁶√7³)² = ⁶√7³² = ⁶√7⁶ = 7 (свойство 3: степень можно занести под корень).

Корень чётной степени из степени

На уроке 2 было: √a² = |a|. То же верно для любой чётной степени, а для нечётной модуль не нужен — корень нечётной степени сохраняет знак.

Правило

n√an = |a| при чётном n;   n√an = a при нечётном n

Пример 5

Вычислить ⁴√(−3)⁴ и ³√(−3)³.

Решение

⁴√81 = 3 = |−3|; ³√−27 = −3.

Будь внимателен

Хочется написать ⁴√(−3)⁴ = −3, но посчитай по шагам: (−3)⁴ = 81, а ⁴√81 = 3. Корень чётной степени всегда неотрицателен, поэтому и нужен модуль.

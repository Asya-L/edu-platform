Равносильные уравнения и неравенства

§ 8 · равносильные преобразования, посторонние и потерянные корни, метод интервалов

▶ Презентация Рабочий лист Домашнее задание

Теория

Попробуй решить «как обычно»: x/(x − 2) = 2/(x − 2). Знаменатели одинаковые — приравняем числители: x = 2. Подставляем и видим, что знаменатель x − 2 обращается в нуль, — выражение не имеет смысла. Где-то по дороге уравнение подменилось другим, у которого корни не те. Чтобы такого не случалось, разберёмся, какие шаги корни сохраняют.

Определение

Два уравнения называются равносильными, если они имеют одни и те же корни (или оба не имеют корней).

Пример: 2x − 6 = 0 и x = 3 равносильны; x² = 9 и x = 3 — нет (у первого есть ещё корень −3).

Равносильные преобразования

  • перенос слагаемого из одной части в другую с противоположным знаком;
  • умножение или деление обеих частей на одно и то же число, не равное нулю;
  • тождественные преобразования (раскрыть скобки, привести подобные), если они не меняют область допустимых значений.

Область допустимых значений (ОДЗ) — все значения x, при которых обе части уравнения имеют смысл: знаменатели не равны нулю, под корнем чётной степени не отрицательное число. Например, для x/(x − 2) = 2/(x − 2) ОДЗ: x ≠ 2. А сокращение (x − 1)/(x − 1) = 1 ОДЗ расширяет: слева x = 1 было запрещено, справа — нет.

Следствие

Если все корни первого уравнения являются корнями второго, то второе называют следствием первого. У следствия могут появиться лишние корни — их называют посторонними.

Откуда берутся посторонние корни

  1. Возведение в квадрат. √x = x − 2 ⇒ x = x² − 4x + 4 ⇒ x² − 5x + 4 = 0 ⇒ x = 1 или x = 4. Проверка: при x = 1 слева 1, справа −1 — посторонний. Ответ: 4. Откуда он взялся: после возведения в квадрат минус пропадает, и мы заодно решаем уравнение √x = −(x − 2). Его корень x = 1 и «пролез» в ответ.
  2. Расширение ОДЗ (например, умножение на знаменатель). x/(x − 2) = 2/(x − 2): умножаем на x − 2 и получаем x = 2. Но в уравнении x = 2 запрета x ≠ 2 уже нет, а в исходном он был: при x = 2 знаменатель равен нулю. Корней нет.
Будь внимателен

Если при решении было возведение в чётную степень или умножение на выражение с переменной — проверка обязательна. Это не формальность, а часть решения: такие шаги дают уравнение-следствие, в котором могут появиться посторонние корни.

Как теряются корни

Делить обе части на выражение с переменной нельзя: x(x − 2) = 3(x − 2). Если разделить на x − 2, получим x = 3 и потеряем корень x = 2: при x = 2 мы делили бы на ноль, а этого делать нельзя. Правильно: перенести всё в одну часть и разложить на множители: (x − 2)(x − 3) = 0, x = 2 или x = 3.

Пример 1

Решить √(x + 2) = x.

Решение

x + 2 = x² ⇒ x² − x − 2 = 0 ⇒ x = 2 или x = −1. Проверка: √4 = 2 ✓; √1 = 1 ≠ −1 ✗. Ответ: 2.

Равносильные неравенства

Неравенства равносильны, если множества их решений совпадают. Равносильные преобразования неравенств:

  • перенос слагаемого с противоположным знаком;
  • умножение или деление на положительное число — знак неравенства сохраняется;
  • умножение или деление на отрицательное число — знак неравенства меняется на противоположный.
Будь внимателен

Умножать неравенство на выражение с переменной (например, на знаменатель) нельзя: неизвестен его знак, а значит, неизвестно, менять ли знак неравенства. При x = 0 множитель x + 2 положителен, а при x = −5 — отрицателен. Неравенство (x − 1)/(x + 2) > 0 решают методом интервалов, а не «умножением на x + 2».

Метод интервалов

  1. Перенести всё в одну часть, чтобы справа был 0.
  2. Найти нули числителя и знаменателя и отметить их на прямой (нули знаменателя — всегда выколотые).
  3. Определить знак в каждом промежутке: подставить любое удобное число из него. Внутри промежутка знак не меняется — он может смениться только в нуле числителя или знаменателя.
  4. Выбрать промежутки с нужным знаком. Если неравенство нестрогое (≥ или ≤), нули числителя входят в ответ (закрашенные точки), нули знаменателя — никогда.
Пример 2

Решить (x − 1)/(x + 2) > 0.

Решение

Справа уже 0. Нули: числитель — x = 1, знаменатель — x = −2. Неравенство строгое, обе точки выколотые.

Знаки: при x = −3 дробь (−4)/(−1) = 4 > 0; при x = 0 дробь −1/2 < 0; при x = 2 дробь 1/4 > 0. Получаем +, −, + на (−∞; −2), (−2; 1), (1; +∞).

Нужен знак «+». Ответ: (−∞; −2) ∪ (1; +∞).

Пример 3 · нестрогое неравенство

Решить (x − 4)/(x + 1) ≥ 0.

Решение

Нули: x = 4 (числитель) — точка закрашенная, ведь при x = 4 дробь равна 0, а 0 ≥ 0 подходит; x = −1 (знаменатель) — выколотая, на ноль делить нельзя.

Знаки: при x = −2 дробь (−6)/(−1) = 6 > 0; при x = 0 дробь −4 < 0; при x = 5 дробь 1/6 > 0.

Ответ: (−∞; −1) ∪ [4; +∞).

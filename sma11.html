и функция y = ⁿ√x

Определение

Корень n-й степени из a

ОпределениеЧисло, n-я степень которого равна a.

⁵√32 = 2  ·  ∛(−64) = −4  ·  корни 4-й степени из 81: 3 и −3

Арифметический корень

ⁿ√a ≥ 0

ВажноЧётная степень: ⁿ√a — только неотрицательный корень из a ≥ 0. ⁴√16 = 2, не ±2.

Нечётная степень: ⁿ√a есть для любого a, ∛(−8) = −2.

Уравнение

xⁿ = a

  1. n нечётное: x = ⁿ√a
  2. n чётное, a > 0: x = ±ⁿ√a
  3. n чётное, a < 0: корней нет

Неравенства

Следим за областью определения

  1. ⁴√(x − 2) < 1 ⇔ 0 ≤ x − 2 < 1 ⇒ [2; 3)
  2. ⁶√(x² − 4) > ⁶√(3x) ⇒ (4; +∞)
  3. ∛(x² − 4) > ∛(3x) ⇒ (−∞; −1) ∪ (4; +∞)

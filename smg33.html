Типичные ошибки

  1. угол между прямыми / плоскостями тупым не бывает
  2. признак 10.1 — только с пересекающимися прямыми
  3. ТТП — только с доказанным перпендикуляром
  4. стороны линейного угла ⊥ ребру
  5. S_пр = S cos φ — только для ортогональной проекции

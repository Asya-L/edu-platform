Алгебра

Множества

A ∩ B — общие, A ∪ B — все, A ∖ B — из A, но не из B.

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

У множества из n элементов 2ⁿ подмножеств.

Логика

A ⇒ B ложно только при A = 1, B = 0.

A ⇒ B ≡ B̄ ⇒ Ā (контрапозиция); ¬(A ∧ B) = Ā ∨ B̄, ¬(A ∨ B) = Ā ∧ B̄.

Отрицание: ∀ ↔ ∃, свойство заменяем противоположным.

Виды теорем и условия

Теорема A ⇒ B; обратная B ⇒ A; противоположная Ā ⇒ B̄.

В A ⇒ B: A — достаточное условие для B, B — необходимое для A. Обе верны — критерий (⇔).

Периодические дроби

0,(ab) = ab/99

0,a(b) = (ab − a)/90

Пример: 1,2(7) = (127 − 12)/90 = 23/18.

Убывающая прогрессия

|q| < 1: S = b₁ / (1 − q)

Отсюда b₁ = S(1 − q), q = 1 − b₁/S.

Функции и графики

Чётная: D симметрична и f(−x) = f(x); нечётная: f(−x) = −f(x).

  • f(x − a) + b — сдвиг на a вправо и b вверх
  • −f(x) — отражение от Ox; f(−x) — от Oy
  • |f(x)| — нижнюю часть вверх; f(|x|) — правую часть отразить влево

Обратная функция

  1. Выразить x через y.
  2. Поменять x и y.
  3. D и E меняются местами.

Графики симметричны относительно y = x. Функция обратима, если она монотонна.

Метод интервалов

  1. Всё в одну сторону, разложить на множители.
  2. Нули числителя и знаменателя на ось (знаменатель — выколот).
  3. Знак на одном промежутке — пробной точкой.
  4. Через корень чётной кратности знак не меняется.

Корни

ⁿ√(ab) = ⁿ√a · ⁿ√b, ⁿ√(a/b) = ⁿ√a / ⁿ√b

(ⁿ√a)ᵐ = ⁿ√(aᵐ), ⁿ√(ᵐ√a) = ⁿᵐ√a

Корень нечётной степени из отрицательного числа: ³√(−8) = −2. Чётной: ⁴√(a⁴) = |a|.

Где определены корни и степени

ⁿ√a при нечётном n — для любого a, при чётном — для a ≥ 0.

xm/n определена при x ≥ 0 (при m/n < 0 — при x > 0): ∛x и x1/3 — разные функции.

При замене t = √x не забыть t ≥ 0.

Степени

am/n = ⁿ√(aᵐ), a > 0

aˣ·aʸ = aˣ⁺ʸ, (aˣ)ʸ = aˣʸ, a⁻ˣ = 1/aˣ

Сравнение: при a > 1 больше показатель — больше степень; при 0 < a < 1 — наоборот.

Степенная функция y = xᵖ

  • p чётное натуральное — парабола, чётная функция
  • p нечётное — нечётная функция, возрастает
  • p > 0 нецелое — x ≥ 0, возрастает
  • p < 0 нецелое — x > 0, убывает

Равносильность

Равносильны — одинаковые множества корней.

Опасно: возведение в чётную степень, умножение на выражение с переменной, расширение области — могут дать посторонние корни ⟹ проверка обязательна.

Опасно: деление на выражение с переменной — можно потерять корни.

Иррациональные уравнения

  1. Уединить корень.
  2. Возвести обе части в квадрат (в куб).
  3. Решить полученное уравнение.
  4. Проверка подстановкой — посторонние корни отбросить.

Без проверки: √f = g ⇔ f = g², g ≥ 0

Иррациональные неравенства

√f < g ⇔ f ≥ 0, g > 0, f < g²

√f > g ⇔ [g < 0, f ≥ 0] или [g ≥ 0, f > g²]

√f < √g ⇔ 0 ≤ f < g

Возводить в квадрат можно, только когда обе части ≥ 0.

Показательная функция y = aˣ

a > 0, a ≠ 1; D = ℝ, E = (0; +∞); график проходит через (0; 1), ось Ox — асимптота.

a > 1 — возрастает, 0 < a < 1 — убывает.

aˣ = aʸ ⇔ x = y; графики y = aˣ и y = (1/a)ˣ симметричны относительно оси Oy.

Радианы

π рад = 180°, 1 рад ≈ 57°.

Длина дуги l = αR, площадь сектора S = αR² / 2 (α — в радианах).

Синус, косинус, тангенс

Поворот точки (1; 0) на угол α по единичной окружности: cos α = x, sin α = y.

tg α = sin α / cos α, ctg α = cos α / sin α.

−1 ≤ sin α, cos α ≤ 1; повторяются через 2π (tg, ctg — через π).

Знаки и чётность

sin > 0 в I и II четвертях; cos > 0 в I и IV; tg, ctg > 0 в I и III.

cos(−α) = cos α — чётная; sin(−α) = −sin α, tg и ctg — нечётные.

Геометрия

Аксиомы

А1. Через три точки, не лежащие на одной прямой, — одна плоскость.

А2. Две точки прямой в плоскости ⟹ вся прямая в плоскости.

А3. Общая точка двух плоскостей ⟹ общая прямая.

Плоскость задают

  • три точки не на одной прямой
  • прямая и точка вне её
  • две пересекающиеся прямые
  • две параллельные прямые

Две прямые

  • пересекаются — одна общая точка
  • параллельны — в одной плоскости, нет общих точек
  • скрещиваются — не в одной плоскости

Признак: одна в плоскости, другая пересекает её в точке вне первой.

Прямая и плоскость

Лежит · пересекает в точке · параллельна (нет общих точек).

Признак ∥: a ⊄ α, a ∥ b, b ⊂ α ⟹ a ∥ α.

1° Плоскость через a ∥ α режет α по прямой ∥ a.

Две плоскости

Пересекаются по прямой · параллельны.

Признак ∥: две пересекающиеся прямые одной ∥ двум прямым другой.

1° Третья плоскость режет ∥ плоскости по ∥ прямым. 2° Отрезки ∥ прямых между ∥ плоскостями равны.

Угол между прямыми

От 0° до 90°. Для скрещивающихся: переносим одну прямую параллельно до пересечения со второй.

Куб: AB, CC₁ — 90°; AB, A₁C₁ — 45°; AD₁, DC₁ — 60°.

Тетраэдр и параллелепипед

Тетраэдр: 4 грани, 6 рёбер, 4 вершины; противоположные рёбра скрещиваются.

Параллелепипед: 6 граней, 12 рёбер, 8 вершин, 4 диагонали; противоположные грани ∥ и равны; диагонали делятся точкой пересечения пополам.

Сечения: три правила

  1. Соединяем только точки одной грани.
  2. На параллельных гранях — параллельные отрезки.
  3. Метод следов: продлеваем отрезок и ребро одной грани до пересечения.

Прямая ⊥ плоскости

Перпендикулярна любой прямой плоскости.

Признак: перпендикулярна двум пересекающимся прямым плоскости.

Две прямые ⊥ одной плоскости параллельны.

Перпендикуляр и наклонная

Перпендикуляр короче любой наклонной из той же точки.

Равные наклонные ⇔ равные проекции; бо́льшая наклонная ⇔ бо́льшая проекция.

Расстояние от точки до плоскости — длина перпендикуляра.

Теорема о трёх перпендикулярах

Прямая в плоскости ⊥ проекции наклонной ⟺ она ⊥ самой наклонной.

Применяют, чтобы найти расстояние от точки до прямой и линейный угол двугранного угла.

Углы в пространстве

Прямая и плоскость — угол между прямой и её проекцией (0°–90°).

Двугранный угол — измеряют линейным: оба луча ⊥ ребру в одной точке.

Между плоскостями — от 0° до 90°.

Перпендикулярные плоскости

Признак: одна плоскость проходит через прямую, ⊥ другой.

Прямая в одной из ⊥ плоскостей, ⊥ линии пересечения, ⊥ другой плоскости.

Площадь проекции и трёхгранный угол

Sпр = S · cos φ, φ — угол между плоскостями.

Теорема косинусов: cos a = cos b · cos c + sin b · sin c · cos α

Каждый плоский угол меньше суммы двух других; сумма плоских углов < 360°.

Теорема Эйлера

Для выпуклого многогранника В − Р + Г = 2.

n-угольная призма: 2n вершин, 3n рёбер, n + 2 граней. Пирамида: n + 1, 2n, n + 1.

Призма

Прямая: Sбок = Pосн · h, Sполн = Sбок + 2Sосн

Наклонная: Sбок = P⊥ · l — периметр перпендикулярного сечения на боковое ребро.

Параллелепипед

Диагонали пересекаются в одной точке и делятся ею пополам.

Прямоугольный: d² = a² + b² + c²

Пространственная теорема Пифагора (прямые плоские углы при вершине): S² = S₁² + S₂² + S₃²

Правильная пирамида

Основание — правильный многоугольник, высота падает в его центр. Апофема m — высота боковой грани.

Sбок = ½ Pосн · m

Куда падает высота пирамиды

Равные боковые рёбра (или равные углы рёбер с основанием) — в центр описанной окружности основания.

Равные двугранные углы при основании — в центр вписанной окружности; тогда Sбок = Sосн / cos φ.

ЕГЭ · формулы стереометрии (задания 3 и 14)

Призма и параллелепипед

V = Sосн · h

Прямоугольный параллелепипед: V = abc, d² = a² + b² + c²

Куб: V = a³, d = a√3, S = 6a²

Пирамида

V = ⅓ Sосн · h

Правильный тетраэдр с ребром a: высота a√(2/3), объём a³√2 / 12

Цилиндр

V = πR²h

Sбок = 2πRh, Sполн = 2πR(R + h)

Конус

V = ⅓ πR²h

Sбок = πRl, l² = R² + h²

Шар и сфера

V = ⁴⁄₃ πR³, S = 4πR²

Подобие тел

Если линейные размеры увеличить в k раз, площади растут в k² раз, объёмы — в k³ раз.

Сечение пирамиды, параллельное основанию, на расстоянии x от вершины: площадь = Sосн·(x/h)²

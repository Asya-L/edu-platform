§ 1

Целые и рациональные числа

Откуда берутся дроби, почему у дроби бывает период и как от него избавиться

Повторяем

Числа по порядку

N · натуральные1, 2, 3, … — для счёта
Z · целые…, −2, −1, 0, 1, 2, … — чтобы вычитать
Q · рациональныеm/n — чтобы делить

N ⊂ Z ⊂ Q: каждое расширение делает выполнимым ещё одно действие.

Определение

Рациональное число

ОпределениеЧисло вида m/n, где m — целое, n — натуральное.

1/2 = 2/4 = 50/100 — одно число, разные записи.

Часть 1

Дробь → десятичная

Почему появляется период

Делим уголком

3/11 = 0,(27)

  1. 30 : 11 = 2, остаток 8
  2. 80 : 11 = 7, остаток 3
  3. 30 : 11 = 2, остаток 8 — повтор!

Остатков меньше, чем знаменатель, — значит, рано или поздно один повторится.

Признак

Когда дробь конечная

ТеоремаНесократимая дробь — конечная десятичная, если знаменатель раскладывается только на 2 и 5.

7/40 = 0,175  ·  1/6 = 0,1(6)  ·  сначала сократи: 9/75 = 3/25

Часть 2

Периодическая → обыкновенная

Умножаем и вычитаем

Пример

0,(27)

  1. x = 0,2727…
  2. Период из 2 цифр → 100x = 27,2727…
  3. 100x − x = 27 → 99x = 27
  4. x = 27/99 = 3/11

Пример

0,2(45) — смешанная

  1. 10x = 2,4545… — сдвинули предпериод
  2. 1000x = 245,4545…
  3. 990x = 243
  4. x = 243/990 = 27/110

Проверка

Правило девяток

ДробьОбыкновенная

0,(ab)ab/99
0,(abc)abc/999

0,(9) = 9/9 = 1 — одно число, две записи.

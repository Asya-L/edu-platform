Метод интервалов

Идея: выражение вроде (x − 1)(x − 3)/(x − 2) может сменить знак только там, где числитель или знаменатель обращается в ноль. Между такими точками знак постоянный — его достаточно проверить в одной точке.

  1. Перенести всё в одну часть, чтобы справа был 0. Умножать на знаменатель нельзя: его знак неизвестен, а при умножении на отрицательное число знак неравенства меняется.
  2. Разложить на множители, найти нули числителя и знаменателя.
  3. Отметить на прямой: нули знаменателя — всегда выколотые (на ноль делить нельзя); нули числителя — закрашенные при ≥, ≤ и выколотые при >, <.
  4. Расставить знаки: проверить знак в одной точке, дальше знаки чередуются. Исключение — корень чётной кратности, когда множитель стоит в чётной степени, например (x − 4)²: такой множитель не бывает отрицательным, и при переходе через x = 4 знак не меняется.
  5. Выбрать нужные промежутки и записать ответ.
Пример 1

Решите неравенство (x² − 4x + 3)/(x − 2) ≥ 0.

Решение

Шаг 1. x² − 4x + 3 = (x − 1)(x − 3), неравенство: (x − 1)(x − 3)/(x − 2) ≥ 0.

Шаг 2. Нули числителя 1 и 3 — закрашенные (в них дробь равна 0, а «≥ 0» это допускает). Нуль знаменателя 2 — выколотый.

Шаг 3. Знак справа от 3: при x = 4 получаем (3 · 1)/2 > 0, «+». Дальше знаки чередуются; слева направо: −, +, −, +.

Шаг 4. Берём промежутки с «+» и закрашенные точки. Ответ: [1; 2) ∪ [3; +∞).

Показательные и логарифмические

Функция y = 2ˣ возрастает: большему показателю соответствует большее значение. А y = (1/2)ˣ убывает: (1/2)¹ = 1/2, но (1/2)² = 1/4 — показатель больше, значение меньше. Поэтому при основании от 0 до 1 знак неравенства при переходе к показателям (или к выражениям под логарифмом) меняется на противоположный. С логарифмами помним ещё одно: под логарифмом может стоять только положительное число.

НеравенствоПереход
aᶠ > aᵍ, a > 1f > g
aᶠ > aᵍ, 0 < a < 1f < g (знак меняется)
logₐ f > logₐ g, a > 1f > g > 0
logₐ f > logₐ g, 0 < a < 10 < f < g
Пример 2

Решите неравенство 4ˣ − 6 · 2ˣ + 8 ≤ 0.

Решение

Замена t = 2ˣ, t > 0; тогда 4ˣ = (2ˣ)² = t². t² − 6t + 8 ≤ 0 → (t − 2)(t − 4) ≤ 0 → 2 ≤ t ≤ 4.

Обратная замена: 2¹ ≤ 2ˣ ≤ 2², основание 2 > 1, знаки сохраняются: 1 ≤ x ≤ 2. Ответ: [1; 2].

Пример 3

Решите неравенство log₀,₅(x − 1) ≥ −2.

Решение

Запишем −2 как логарифм по основанию 0,5: −2 = log₀,₅4, так как 0,5⁻² = 2² = 4. Неравенство: log₀,₅(x − 1) ≥ log₀,₅4.

Основание 0,5 < 1 — знак меняется, а выражение под логарифмом должно быть положительным: 0 < x − 1 ≤ 4 → 1 < x ≤ 5. Ответ: (1; 5].

Будь внимателен

Две самые частые ошибки: забыть, что под логарифмом стоит положительное число (ответ «x ≤ 5» вместо «1 < x ≤ 5»), и не поменять знак при основании меньше 1. Проверка помогает: при x = 0 выражение log₀,₅(x − 1) вообще не существует, значит, ответ «x ≤ 5» неверен.

Метод рационализации

Иногда в произведении стоит «сложный» множитель, например 3ˣ − 9. Для метода интервалов важен только его знак, поэтому его можно заменить простым множителем того же знака (на ОДЗ). Почему: функция y = 3ˣ возрастает, поэтому 3ˣ − 3² > 0 ровно тогда, когда x > 2, — знак 3ˣ − 9 совпадает со знаком x − 2. Общие правила:

МножительЗаменяем на
aᶠ − aᵍ(a − 1)(f − g)
logₐf − logₐg(a − 1)(f − g)
|f| − |g|(f − g)(f + g)
√f − √gf − g

Множитель (a − 1) отвечает за основание: при a > 1 он положительный и знак не меняет, при 0 < a < 1 — отрицательный и «переворачивает» знак. В решении каждую замену обосновывают одной фразой, как выше.

Пример 4

Решите неравенство (3ˣ − 9)(x − 5) ≤ 0.

Решение

3ˣ − 9 = 3ˣ − 3² имеет тот же знак, что x − 2, так как функция y = 3ˣ возрастает. Неравенство равносильно (x − 2)(x − 5) ≤ 0 → 2 ≤ x ≤ 5. Ответ: [2; 5].

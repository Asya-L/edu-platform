Метод интервалов

  1. Перенести всё в одну часть: справа 0. Не умножать на знаменатель!
  2. Разложить на множители, найти нули числителя и знаменателя.
  3. Отметить на прямой: нули знаменателя — всегда выколотые; нули числителя — закрашенные при ≥, ≤.
  4. Расставить знаки (проверка одной точкой). При корне чётной кратности знак не меняется.
  5. Выбрать нужные промежутки и записать ответ.
Пример 1

Решите неравенство (x² − 4x + 3)/(x − 2) ≥ 0.

Решение

(x − 1)(x − 3)/(x − 2) ≥ 0. Точки 1, 3 (закрашенные), 2 (выколотая). Знаки справа налево: +, −, +, −. Ответ: [1; 2) ∪ [3; +∞).

Пример 2

Решите неравенство 4ˣ − 6 · 2ˣ + 8 ≤ 0.

Решение

t = 2ˣ > 0: t² − 6t + 8 ≤ 0 → 2 ≤ t ≤ 4 → 1 ≤ x ≤ 2. Ответ: [1; 2].

Пример 3

Решите неравенство log₀,₅(x − 1) ≥ −2.

Решение

log₀,₅(x − 1) ≥ log₀,₅4, основание меньше 1: 0 < x − 1 ≤ 4. Ответ: (1; 5].

Будь внимателен

Главные потери балла: забыли ОДЗ логарифма (ответ «x ≤ 5» вместо «1 < x ≤ 5») и не поменяли знак при основании меньше 1.

Метод рационализации

В неравенствах вида «произведение/частное ≥ 0» сложный множитель можно заменить простым того же знака (на ОДЗ):

МножительЗаменяем на
aᶠ − aᵍ(a − 1)(f − g)
logₐf − logₐg(a − 1)(f − g)
|f| − |g|(f − g)(f + g)
√f − √gf − g
Пример 4

Решите неравенство (3ˣ − 9)(x − 5) ≤ 0.

Решение

3ˣ − 3² ↔ (x − 2): (x − 2)(x − 5) ≤ 0. Ответ: [2; 5].

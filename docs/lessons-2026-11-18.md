`mg24` — внутренний адрес, а не номер параграфа учебника. Задания и объяснения
составлены для платформы. Каждый комплект содержит конспект, три разобранных
примера, шесть классных задач, шесть домашних задач, десять слайдов, рабочий лист
и две самопроверки по шесть вопросов. Классные и домашние задачи различаются.

Ученические PDF находятся в `files/`. Решения, заметки учителя, учительские PDF
и резервные авторские JSON находятся только в зашифрованных `t/*.bin`,
`t/files/*.bin`, `t/sources/*.bin`. Используется действующий формат загрузчика:
AES-256-GCM, IV 12 байт, шифротекст, тег 16 байт. Ключ не менялся.
Восемь прежних страниц учителя сохранены с добавлением навигации к новым урокам.

В журнал добавлены полные условия ДЗ и соответствующий домашний тест. Все четыре
колоды доступны на доске. Правильные ответы самопроверок возвращает существующая
`edu_check_quiz` после отправки попытки; в публичном HTML ключей нет.

## Повторная сборка владельцем

Нужны приватные авторские JSON, действующий ключ содержимого и исходные восемь
зашифрованных страниц `old-t-{course-or-previous-lesson}.bin`. Они хранятся вне Git
в игнорируемом `.private-lessons/`. Резервные авторские JSON можно восстановить
из `t/sources/` тем же ключом. Исходные PDF учебников в репозиторий не включаются.

```sh
node scripts/connect_lesson_pack.js PRIVATE_INPUT_DIR KEY_FILE
python3 scripts/build_lesson_pack.py --input-dir PRIVATE_INPUT_DIR --key-file KEY_FILE
node scripts/connect_lesson_pack.js PRIVATE_INPUT_DIR KEY_FILE
python3 scripts/version_catalogs.py
node scripts/render_lesson_pack.js PRIVATE_INPUT_DIR KEY_FILE
LESSON_PRIVATE_INPUT=PRIVATE_INPUT_DIR npm test
```

Порядок сначала обновляет маршрутизацию, затем фиксирует её версию в новых
страницах. Рендерер проверяет переполнение слайдов и создаёт PDF. Снимки страниц
PDF и колод нужно также просмотреть визуально. Повторное шифрование меняет IV.

Перед первой публикацией добавлены 48 ответов только для восьми новых тестов.
Существующие ответы не перезаписываются: при несовпадении операция останавливается.
Реальная проверка оценивания и отправки четырёх листов выполнена с вымышленным
учеником; все его данные откатились внутри транзакции. Схема базы не менялась.

Обычный `npm test` не подключается к рабочей базе. Приватный дополнительный режим
проверяет настоящие зашифрованные страницы; CI использует синтетические ответы
и проверяет защиту от входа ученика в учительский раздел.

# Общие учебные каталоги

`assets/catalogs.js` — единственное место для одинаковых учебных справочников главной
страницы, журнала, домашнего задания и успеваемости. Полный набор повторялся четырежды:
в двух блоках главной страницы и по одному разу в журнале и домашке. В успеваемости
были ещё копии названий тестов и рабочих листов.

Объект `data` содержит:

- `groups` — группы и темы; словарь `topics` вычисляется из них автоматически;
- `quizzes` — названия тестов;
- `worksheets` — названия рабочих листов;
- `homeworkHints` — источники и подсказки для домашних заданий.

Это публичные данные, которые уже присутствовали в HTML. Ключи ответов и персональные
данные сюда не добавляют. Названия листов включают существующие справочные записи;
выделение общего каталога не создаёт новых страниц и не меняет прежние ссылки.

В браузере модуль доступен как `window.EDU_CATALOG`, в проверках Node — через `require`.
Общие данные защищены от изменения. `copyHomeworkHints()` выдаёт независимую копию:
журнал подставляет в неё полные условия ЕГЭ из `assets/homework-ege.js`, не меняя
подсказки других блоков. Источником полных условий остаются `el1.html`–`el20.html`.

После изменения каталога:

```sh
python3 scripts/version_catalogs.py
npm test
```

Первая команда автоматически обновляет версию ссылки на общий файл на всех четырёх
страницах. Проверки требуют совпадения версии с содержимым файла, поэтому новая
публикация не оставит старый каталог в браузерном кеше.

`catalogs.test.js` проверяет ссылки на тесты, связность подсказок и изоляцию копий.
`catalogs-browser.js` проверяет оба блока главной, темы и ссылки в домашке, все
варианты тем в журнале, названия листов и подстановку полного ДЗ ЕГЭ, а также названия и результаты в успеваемости.

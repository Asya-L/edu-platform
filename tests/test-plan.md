# Кабинет математики — тест-план

Окружения:
- **A** — локальная копия сайта + имитация Supabase (Playwright, `tests/e2e.js`). Проверяет интерфейс, роли, шифрование, журнал и ДЗ.
- **B** — живой Supabase: `tests/db-check.sql` в SQL Editor — создаёт временных учеников, проверяет DB-01…08 и откатывает все изменения (отчёт приходит сообщением «ИТОГ ПРОВЕРКИ»).
- **C** — живой сайт на GitHub Pages в браузере без входа.

Приоритет: **P1** — блокирует работу или открывает ответы ученику, **P2** — заметно мешает, **P3** — косметика.

## 1. Вход и сессия
| ID | Сценарий | Ожидание | Где | P |
|---|---|---|---|---|
| AUTH-01 | Гость открывает любую страницу материалов | Перенаправление на `login.html?next=…` | A, C | P1 |

| AUTH-04 | Вход учителя | Переход в `t.html#index` | A | P1 |

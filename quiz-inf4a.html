Домашняя работа: учитель увидит результат первой попытки.

1. Уже заданы 00, 01, 101. Впиши самое короткое слово, не нарушающее условие Фано. При равной длине выбери наименьшее числовое значение.

2. Уже заданы 1, 001, 010. Впиши самое короткое слово, не нарушающее условие Фано. При равной длине выбери наибольшее числовое значение.

3. Уже заданы 0, 100, 101, 111. Впиши самое короткое слово, не нарушающее условие Фано. При равной длине выбери наименьшее числовое значение. Оставь место ещё для одной буквы.

4. В каком наборе выполняется прямое условие Фано?

5. Коды: А — 0, Б — 10, В — 110, Г — 111. Расшифруй 110111010 и запиши буквы без пробелов.

6. Коды: А — 00, Б — 01, В — 10, Г — 110, Д — 111. Сколько бит занимает слово ВАГД?

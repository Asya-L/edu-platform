Выражения

Пример 1 · скобки

Упростить 3(2x − 5) − 2(4x − 7).

Решение

6x − 15 − 8x + 14 = −2x − 1. Минус перед скобкой меняет знаки всех слагаемых.

Формулы сокращённого умножения работают в обе стороны. Слева направо — раскрываем скобки. Справа налево («наоборот») — сворачиваем выражение в квадрат или произведение; так удобно и упрощать, и считать устно.

ФормулаПример «наоборот»
(a + b)² = a² + 2ab + b²101² = 10000 + 200 + 1 = 10201
(a − b)² = a² − 2ab + b²x² − 6x + 9 = (x − 3)²
a² − b² = (a − b)(a + b)37² − 27² = 10 · 64 = 640
Пример 2 · дробь с буквами

Сократить (x² − 5x + 6)/(x − 2).

Решение

x² − 5x + 6 = (x − 2)(x − 3), поэтому дробь равна x − 3 при x ≠ 2.

Будь внимателен

Сокращают только множители, а не слагаемые: (x + 2)/2 ≠ x + 1. Проверь на числе: при x = 4 слева (4 + 2)/2 = 3, а справа 4 + 1 = 5. Чтобы появились множители — вынести общий, применить формулу или разложить квадратный трёхчлен по корням.

Пять типов уравнений задания 7

ОДЗ

ОДЗ (область допустимых значений) — все x, при которых каждое выражение в уравнении имеет смысл: знаменатель не равен нулю, под квадратным корнем стоит неотрицательное число. Например, для √(x − 3) + 1/(x − 5) ОДЗ: x ≥ 3 и x ≠ 5. Корень, который не входит в ОДЗ, в ответ не берут.

Пример 3 · квадратное

Решите уравнение x² + 3x − 10 = 0. Если корней несколько, укажите меньший.

Решение

Теорема Виета для x² + bx + c = 0: x₁ + x₂ = −b, x₁ · x₂ = c. Здесь x₁ + x₂ = −3, x₁ · x₂ = −10. Подбираем: 2 и −5 (проверка: 2 + (−5) = −3, 2 · (−5) = −10). Если подобрать не получается — считай через дискриминант: D = 9 + 40 = 49, x = (−3 ± 7)/2. Меньший корень: −5.

Пример 4 · дробное

Решите уравнение 6/(x − 4) = 3/(x + 1).

Решение

ОДЗ: x ≠ 4 и x ≠ −1 (знаменатели не равны нулю). По свойству пропорции перемножаем «крест-накрест»: 6(x + 1) = 3(x − 4) → 6x + 6 = 3x − 12 → 3x = −18 → x = −6. Корень −6 входит в ОДЗ. Ответ: −6.

Пример 5 · иррациональное

Решите уравнение √(x + 7) = x + 1.

Решение

Шаг 1. Возводим обе части в квадрат: x + 7 = (x + 1)² = x² + 2x + 1 → x² + x − 6 = 0 → x = 2 или x = −3.

Шаг 2. Проверка. x = 2: √9 = 3 и 2 + 1 = 3 — верно. x = −3: √4 = 2, а −3 + 1 = −2 — неверно, корень посторонний. Ответ: 2.

Будь внимателен

Почему после возведения в квадрат нужна проверка: квадрат «стирает» знак. Неверное равенство −2 = 2 после возведения в квадрат превращается в верное 4 = 4. Так и появляется посторонний корень x = −3: корень √(x + 7) не бывает отрицательным, а x + 1 при x = −3 равно −2. Поэтому каждый найденный корень подставляй в исходное уравнение.

Пример 6 · показательное

Решите уравнение (1/2)x + 1 = 8.

Решение

Приводим к основанию 2: 1/2 = 2⁻¹, поэтому (1/2)x + 1 = 2−(x + 1); 8 = 2³. Если степени с одинаковым основанием равны, равны и показатели: −x − 1 = 3 → x = −4.

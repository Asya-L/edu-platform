Подмножество

B ⊂ A

ОпределениеКаждый элемент B является элементом A.

∅ ⊂ A  ·  A ⊂ A  ·  A ⊂ B и B ⊂ A ⇒ A = B

∩ — «и», ∪ — «или», \ — «без»

Пример

Делители 12 и 18

A = {1, 2, 3, 4, 6, 12},   B = {1, 2, 3, 6, 9, 18}

  1. A ∩ B = {1, 2, 3, 6}
  2. A ∪ B = {1, 2, 3, 4, 6, 9, 12, 18}
  3. A \ B = {4, 12},   B \ A = {9, 18}

Промежутки

Смотрим на концы

A = [−2; 5), B = (1; 7]

  1. A ∩ B = (1; 5)
  2. A ∪ B = [−2; 7]
  3. A \ B = [−2; 1]

Условие Фано

От дерева кодов к короткому ответу: проверяем начало слова, находим свободную ветку и оставляем место другим буквам.

СлайдыРабочий листЗадачи парамиДомашкаСамопроверка
Прямое условие Фано

Ни одно кодовое слово не должно быть началом другого. Например, 10 и 101 конфликтуют, а 10 и 110 — нет.

Кодовое слово — строка битов. 01 и 1 — разные слова. Пустое слово обозначается ε: это корень схемы, его буквам не назначают.

Как выбрать код

  1. Отметь занятые слова. Зачеркни всё ниже них: такие слова начинаются с уже занятого кода.
  2. Не бери вершину, под которой есть занятый код: она сама будет его началом.
  3. Иди от коротких слов к длинным. Если на одном уровне осталось несколько вариантов, выбери минимальное или максимальное число по условию. Для равной длины порядок кодов совпадает с их числовым порядком.
  4. Если остались другие буквы, проверь, есть ли для них свободная ветка. Её можно разделить на дочерние ветви добавлением 0 и 1.
Разбор

Даны 0, 100, 101, 110. Для двух новых букв нельзя взять 111 первой: она займёт последнюю свободную ветку целиком. Разделим её на 1110 и 1111. Если нужно наименьшее короткое слово, берём 1110.

Как читать сообщение

Читай слева направо. Как только набралось кодовое слово из таблицы, запиши его букву и начни читать новое. Например, при А — 0, Б — 10, В — 11 строка 10110 делится как 10 | 11 | 0, то есть БВА.

Проверка перебором на Python

Проверяем оба направления: готовое слово может быть началом нового и наоборот.

def fits(candidate, codes):
    return all(not candidate.startswith(w)
               and not w.startswith(candidate)
               for w in codes)

Для задачи на одну новую букву перебирай все слова длины 1, затем 2 и так далее. В задачах с несколькими новыми буквами одной этой проверки недостаточно: нужно проверить оставшиеся ветви.

Полный перебор для одной новой буквы 
from itertools import product

def shortest(codes, largest=False):
    if not codes:
        return '1' if largest else '0'
    order = '10' if largest else '01'
    for length in range(1, max(map(len, codes)) + 2):
        for bits in product(order, repeat=length):
            word = ''.join(bits)
            if fits(word, codes):
                return word
    return None

Достаточно проверить глубину на один уровень ниже самого длинного занятого слова: если где-то есть свободный код, то есть и свободная ветка не глубже этого уровня. Если дерево полностью занято, функция вернёт None.

Задачи парами

Сначала разберите А вместе. Сразу после неё реши Б тем же способом.

1. Найди свободную ветку

А · Вместе. Даны кодовые слова 00, 01, 110. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. Ни одно слово не должно быть началом другого.

Б · Самостоятельно. Даны кодовые слова 00, 10, 010. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. Ни одно слово не должно быть началом другого.

2. Если короткий код занят

А · Вместе. Даны кодовые слова 0, 100, 101. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. Ни одно слово не должно быть началом другого.

Б · Самостоятельно. Даны кодовые слова 1, 010, 011, 000. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. Ни одно слово не должно быть началом другого.

3. Оставь место ещё одной букве

А · Вместе. Даны кодовые слова 0, 100, 101, 110. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. После этого должно остаться место ещё для одной буквы. Ни одно слово не должно быть началом другого.

Б · Самостоятельно. Даны кодовые слова 1, 000, 001, 010. Найди самое короткое слово для новой буквы. Если вариантов несколько, выбери наименьшее по числовому значению. После этого должно остаться место ещё для одной буквы. Ни одно слово не должно быть началом другого.

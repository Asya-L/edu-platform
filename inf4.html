Условие Фано

Разбираемся, как читать сообщение из нулей и единиц и как выбрать код для новой буквы.

▶ Презентация Рабочий лист Домашнее задание

Теория

1. Зачем нужно условие Фано

Представь, что буквы передают нулями и единицами. Например, буквам А, Б и В дали коды 1, 10 и 0. Каждый ноль и каждая единица — один бит. Пробелов между кодами нет.

Получили 10. Можно прочитать всё сразу как Б. Можно разделить 1 | 0 и прочитать АВ. По одной записи получилось два сообщения.

Прямое условие Фано

Коды для букв выбирают так, чтобы ни один код не совпадал с началом кода другой буквы. Тогда, как только при чтении встретился целый код, можно сразу записать его букву.

Два кодаМожно ли использовать вместе?
10 и 101Нет. Первые два символа 101 — это 10.
10 и 110Да. У 110 первые два символа 11.
01 и 1Да. Запись 01 начинается с нуля. Для кодов важна каждая цифра, включая первую.

2. Как найти самый короткий свободный код

Удобно рисовать дерево. Сверху пока нет кода. Первый шаг даёт 0 или 1. Следующий шаг добавляет ещё одну цифру справа. Так из 1 получаются 10 и 11.

Пример 1 · Одна новая буква

Даны 00, 01 и 110. Какой самый короткий код можно добавить?

Решение
  1. Проверяем коды длины 1. 0 нельзя взять, потому что с него начинаются 00 и 01. 1 тоже занять нельзя, с него начинается 110.
  2. Проверяем 00, 01, 10, 11. Первые два кода уже заняты. С 11 начинается 110.
  3. Остался 10. Ни один занятый код с него не начинается. Сам 10 тоже не начинается с занятого кода. Ответ 10.
Проверь в обе стороны

Если уже взяли 10, то нельзя добавить 1. Это начало кода 10. Добавить 101 тоже нельзя. Он сам начинается с 10.

Когда нашлось несколько кодов одной длины, смотри, какой просят в условии. Например, из 001 и 011 меньший — 001. Первая цифра у них одинаковая, а во второй позиции 0 меньше 1. Если просят наибольший, берём 011.

3. Что меняется, если новых букв две

Пример 2 · Две новые буквы

Даны 0, 100, 101 и 110. Найди самый короткий код для первой из двух новых букв. Если есть выбор, бери меньший код.

Решение
  1. Все коды, начинающиеся с 0, сразу исключаем. Код 0 уже занят.
  2. Проверяем начало с 1. Короткие варианты 1, 10 и 11 начинают занятые коды. Из 100, 101, 110, 111 свободен только 111.
  3. Если дать 111 первой букве, вторая не сможет взять ни 1110, ни 1111. Они начинаются с кода первой буквы.
  4. Вместо этого сразу выбираем 1110 и 1111. Оба кода одной длины и различаются последней цифрой. Поэтому ни один из них не является началом другого. Первой букве даём меньший. Ответ 1110.

4. Как прочитать сообщение и посчитать его длину

Пример 3 · Декодирование

А — 0, Б — 10, В — 11. Прочитай сообщение 10110.

Решение
  1. Смотрим на первую цифру 1. Такого кода в таблице нет. Берём ещё одну цифру. 10 — это Б. Остаётся 110.
  2. Читаем следующие 11. Это В. Остаётся 0.
  3. 0 — это А. Проверяем, как разделили запись. Получилось 10 | 11 | 0. Ответ БВА.

Если спросят длину этого сообщения, сложим длины трёх кодов. Получим 2 + 2 + 1 = 5 бит.

Дополнительно · как проверить код в Python

Команда a.startswith(b) отвечает на вопрос «начинается ли a с b?». Для каждой пары проверяем оба порядка. Сначала смотрим, с чего начинается новый код, затем — с чего начинается занятый. Записываем коды в кавычках, чтобы сохранить начальные нули.

def fits(candidate, codes):
    for used in codes:
        if candidate.startswith(used) or used.startswith(candidate):
            return False
    return True

codes = ["00", "01", "110"]
print(fits("11", codes))  # False
print(fits("10", codes))  # True

Эта проверка отвечает, можно ли добавить один код. Когда нужны два новых кода, после первого выбора ещё нужно проверить, что для второго осталось место.

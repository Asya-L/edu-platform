ОДЗ

Сокращаем множители

Пример(x² − 5x + 6)/(x − 2) = x − 3,  x ≠ 2

Слагаемые не сокращают: (x + 2)/2 ≠ x + 1.

Внимание

Проверка корней

√(x + 7) = x + 1 ⇒ x² + x − 6 = 0 ⇒ x = 2 или −3.

При x = −3 справа −2 < 0 — посторонний.

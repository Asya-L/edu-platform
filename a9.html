Иррациональные уравнения

§ 9 · возведение в степень, уравнение-следствие, посторонние корни и проверка

▶ Презентация Рабочий лист Домашнее задание

Теория

В уравнениях √(x + 1) = x − 1 и ∛(2x − 5) = 3 неизвестное стоит под знаком корня. Такие уравнения называют иррациональными. Ещё примеры: √(x + 15) = x + 3, ∜(x² + 9) = x + 1.

Определение

Уравнение, в котором неизвестное содержится под знаком корня, называется иррациональным.

Будь внимателен

Уравнение x·√3 = 6 — не иррациональное: под корнем стоит число, а не x. Это обычное линейное уравнение, x = 6/√3 = 2√3. Смотри, что именно стоит под корнем.

Два факта о корне, на которых держится вся тема

  1. √a (и любой корень чётной степени) имеет смысл только при a ≥ 0. Под корнем чётной степени не может стоять отрицательное число.
  2. √a ≥ 0 всегда: арифметический корень — неотрицательное число. Поэтому, например, у √(x − 1) = −2 корней нет сразу, без вычислений.

Корень нечётной степени (∛, ⁵√, …) определён для любого числа и может быть отрицательным: ∛(−8) = −2. Для него эти ограничения не действуют.

Как избавиться от корня: возвести в степень

Чтобы «снять» квадратный корень, обе части возводят в квадрат: (√a)² = a. Что при этом происходит с корнями уравнения?

Свойство

При возведении обеих частей уравнения в натуральную степень получается уравнение-следствие: каждый корень исходного уравнения является корнем нового.

Доказательство

Пусть x0 — корень уравнения f(x) = g(x). Значит, f(x0) = g(x0) — верное числовое равенство. Равные числа в одной и той же степени дают равные числа: fn(x0) = gn(x0). Значит, x0 — корень уравнения fn(x) = gn(x).

Почему обратное неверно. Из a² = b² следует не только a = b, но и a = −b: 3² = (−3)². Возводя в квадрат, мы заодно решаем «чужое» уравнение, где правая часть с другим знаком. Его корни и становятся посторонними для исходного уравнения.

На рисунке это видно: уравнение x + 2 = x² описывает пересечения прямой y = x и с верхней ветвью y = √(x + 2), и с нижней y = −√(x + 2). Нам нужна только верхняя: x = 2. Точка x = −1 лежит на нижней — это посторонний корень.

Пример 1 · посторонний корень из-за знака

Реши уравнение √(12 − x) = x.

Решение

Возводим в квадрат: 12 − x = x², то есть x² + x − 12 = 0, корни x = 3 и x = −4.

Проверка в исходном уравнении: при x = 3 слева √9 = 3, справа 3 ✓. При x = −4 слева √16 = 4, справа −4 ✗.

Ответ: x = 3.

Будь внимателен

Ошибка: «x = −4 входит в ОДЗ (12 − (−4) = 16 ≥ 0), значит, подходит». ОДЗ проверяет только, что корень можно извлечь. А посторонний корень здесь появился из-за знака правой части: √16 = 4, а не −4. Проверка подстановкой обязательна, одной ОДЗ мало.

Пример 2 · посторонний корень из-за ОДЗ

Реши уравнение √(2x − 3) = √(x − 4).

Решение

Возводим в квадрат: 2x − 3 = x − 4, x = −1.

Проверка: 2·(−1) − 3 = −5 < 0 — корень из отрицательного числа не существует. После возведения в квадрат корни исчезли, а с ними и запрет на отрицательные подкоренные выражения.

Ответ: корней нет.

Чётная и нечётная степень

  • Чётная степень (квадрат, четвёртая): могут появиться посторонние корни — проверка обязательна.
  • Нечётная степень (куб, пятая): получается равносильное уравнение. Функция y = t³ возрастает, поэтому из a³ = b³ следует a = b — «чужого» уравнения с −b не возникает.

И ещё одно полезное утверждение: если обе части уравнения неотрицательны, то возведение в чётную степень даёт равносильное уравнение. Отсюда второй способ решать уравнение вида √f = g: оно равносильно системе g ≥ 0, f = g². Условие g ≥ 0 заменяет проверку, а f ≥ 0 выполнится само: f = g² ≥ 0.

Алгоритм

  1. Уедини корень: оставь его одного в одной части уравнения, всё остальное перенеси в другую.
  2. Возведи обе части в степень, равную показателю корня.
  3. Реши получившееся уравнение. Если корень остался — повтори шаги 1–2.
  4. Проверь каждый найденный корень подстановкой в исходное уравнение (при чётной степени это обязательно).
Пример 3 · сначала уединить корень

Реши уравнение √(x + 3) + 3 = x.

Решение

Уединяем корень: √(x + 3) = x − 3. Квадрат: x + 3 = x² − 6x + 9, x² − 7x + 6 = 0, x = 1 или x = 6.

Проверка: x = 6: √9 + 3 = 6 ✓. x = 1: √4 + 3 = 5 ≠ 1 ✗.

Ответ: x = 6.

Будь внимателен

Если возвести в квадрат, не уединив корень: (√(x + 3) + 3)² — получится x + 3 + 6√(x + 3) + 9, и корень никуда не денется. И главное: (√a + √b)² ≠ a + b, это квадрат суммы, в нём есть удвоенное произведение 2√(ab).

Пример 4 · два корня — возводим дважды

Реши уравнение √(x + 5) + √(x − 3) = 4.

Решение

Квадрат суммы: (x + 5) + 2√((x + 5)(x − 3)) + (x − 3) = 16, откуда √((x + 5)(x − 3)) = 7 − x.

Ещё раз в квадрат: x² + 2x − 15 = 49 − 14x + x², 16x = 64, x = 4.

Проверка: √9 + √1 = 3 + 1 = 4 ✓. Ответ: x = 4.

Пример 5 · корень четвёртой степени

Реши уравнение ∜(5x² − 4) = x.

Решение

Возводим в четвёртую степень: 5x² − 4 = x⁴, x⁴ − 5x² + 4 = 0. Это биквадратное уравнение: x² = 1 или x² = 4, то есть x = ±1, ±2.

Проверка: корень четвёртой степени неотрицателен, поэтому x = −1 и x = −2 не подходят (справа отрицательное число). x = 1: ∜1 = 1 ✓; x = 2: ∜16 = 2 ✓.

Ответ: x = 1, x = 2.

Пример 6 · кубический корень

Реши уравнение ∛(x³ − 7) = x − 1.

Решение

Возводим в куб: x³ − 7 = x³ − 3x² + 3x − 1, 3x² − 3x − 6 = 0, x² − x − 2 = 0, x = 2 или x = −1.

Куб — нечётная степень, уравнение равносильное, посторонних корней нет. Для контроля: ∛1 = 1 = 2 − 1 ✓; ∛(−8) = −2 = −1 − 1 ✓.

Ответ: x = 2, x = −1.

Пример 7 · замена переменной

Реши уравнение x − √x − 6 = 0.

Решение

Пусть t = √x, тогда t ≥ 0 и x = t². Получаем t² − t − 6 = 0, t = 3 или t = −2.

t = −2 не подходит: √x не бывает отрицательным. √x = 3, x = 9. Проверка: 9 − 3 − 6 = 0 ✓.

Ответ: x = 9.

Графический способ

Иногда удобно нарисовать графики левой и правой частей: число точек пересечения — это число корней, а абсцисса точки — сам корень.

Пример 8 · графически

Сколько корней у уравнения √x = 2 − x²? Найди их.

Решение

Слева y = √x возрастает (при x ≥ 0), справа y = 2 − x² при x ≥ 0 убывает. Возрастающая и убывающая функции пересекаются не более чем в одной точке. По рисунку точка (1; 1): √1 = 1 = 2 − 1 ✓.

Ответ: один корень, x = 1.

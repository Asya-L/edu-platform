Взаимно обратные функции

§ 7 · обратимость, как найти обратную функцию, симметрия графиков

▶ Презентация Рабочий лист Домашнее задание

Теория

Функция по каждому x выдаёт y. Иногда нужно наоборот: по y восстановить x. Для y = 2x − 1 это легко: если y = 5, то x = 3, и так для любого y: x = (y + 1)/2. А для y = x² при y = 4 подходят и x = 2, и x = −2 — однозначно «вернуться» нельзя.

Определение

Функция называется обратимой, если каждое своё значение она принимает ровно при одном значении аргумента.

Если функция y = f(x) обратима, то функция, которая каждому y из E(f) ставит в соответствие это единственное x, называется обратной к f. Записывают f−1, а аргумент по привычке снова обозначают x.

Проще говоря: обратная функция «отменяет» действие f. Если f(3) = 5, то f−1(5) = 3.

Будь внимателен

Запись f−1 похожа на степень, но это не 1/f. Для f(x) = 2x − 1: f−1(5) = 3, а 1/f(5) = 1/9. Это просто обозначение обратной функции.

Теорема

Если функция возрастает (или убывает) на промежутке, то она обратима на нём. Обратная функция тоже возрастает (убывает).

Почему: у возрастающей функции большему x соответствует больший y, поэтому два разных x не могут дать один и тот же y. На графике это видно так: функция обратима, если любая горизонтальная прямая пересекает её график не больше одного раза. У параболы y = x² прямая y = 2,25 пересекает график дважды (рисунок выше), а если оставить только правую ветку (x ≥ 0), функция станет обратимой.

Как найти обратную функцию

  1. Проверить, что функция обратима (например, монотонна).
  2. Выразить x через y из равенства y = f(x).
  3. Поменять обозначения: x ↔ y.
  4. Записать область определения обратной: D(f−1) = E(f), E(f−1) = D(f).
Пример 1

Найти функцию, обратную к y = 2x − 1.

Решение

Функция возрастает (угловой коэффициент 2 > 0) ⇒ обратима.

Выражаем x: y = 2x − 1 ⇒ y + 1 = 2x ⇒ x = (y + 1)/2.

Меняем обозначения: y = (x + 1)/2. Проверка на числе: f(3) = 5, и (5 + 1)/2 = 3 ✓.

Пример 2

Найти функцию, обратную к y = x³ + 1.

Решение

Функция возрастает на ℝ. Выражаем x: x³ = y − 1, x = ³√(y − 1) — кубический корень существует при любом y, даже отрицательном (урок 4). Ответ: y = ³√(x − 1).

Графики взаимно обратных функций

Свойство

Графики функции и обратной к ней симметричны относительно прямой y = x: если точка (a; b) лежит на одном графике, то (b; a) — на другом.

Почему: точка (a; b) на графике f означает f(a) = b. Тогда обратная функция переводит b обратно в a: f−1(b) = a, то есть точка (b; a) лежит на её графике. Поменять местами координаты — это и есть отразить точку относительно прямой y = x.

Пример 3

Найти функцию, обратную к y = x², x ≥ 0.

Решение

На [0; +∞) функция возрастает. x = √y (берём неотрицательный корень, так как x ≥ 0). Ответ: y = √x, D = [0; +∞).

Будь внимателен

Частая ошибка — забыть про область определения. Для y = √x обратная — y = x² при x ≥ 0, а не вся парабола: E(√x) = [0; +∞), и это область определения обратной.

Как проверить, что две функции взаимно обратные: применить их по очереди. Запись g(f(x)) значит «сначала посчитай f(x), а потом подставь результат в g». Если в обе стороны снова получается x, функции «отменяют» друг друга.

Пример 4 · проверка

Доказать, что f(x) = 3x + 6 и g(x) = x/3 − 2 взаимно обратные.

Решение

g(f(x)) = (3x + 6)/3 − 2 = x и f(g(x)) = 3(x/3 − 2) + 6 = x. Обе проверки дают x — функции взаимно обратные. На числе: f(1) = 9, g(9) = 3 − 2 = 1 ✓.

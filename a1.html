Целые и рациональные числа

§ 1 · от натуральных чисел к рациональным, периодические дроби

▶ Презентация Рабочий лист Домашнее задание

Теория

Зачем числа «расширяли»

Натуральные числа N = {1, 2, 3, …} появились для счёта. Их можно складывать и умножать, а вычитать — не всегда: 3 − 5 в натуральных числах не выполняется. Добавили ноль и отрицательные числа — получились целые числа Z. Но и в целых не всегда выполняется деление: 3 : 5 — не целое. Добавили дроби — получились рациональные числа Q.

Каждое следующее множество содержит предыдущее: N ⊂ Z ⊂ Q. Расширение каждый раз нужно, чтобы стало выполнимым ещё одно действие.

Определение

Рациональное число — это число вида m/n, где m — целое, n — натуральное.

Одно и то же рациональное число записывается многими дробями: 1/2 = 2/4 = 50/100. Среди них есть одна несократимая.

Дробь в десятичную: откуда берётся период

Делим числитель на знаменатель уголком. Например, 3/11: 30 : 11 = 2 (ост. 8), 80 : 11 = 7 (ост. 3), 30 : 11 = 2 (ост. 8), … Остаток 8 повторился — и дальше цифры пойдут по кругу: 3/11 = 0,272727… = 0,(27).

Почему период неизбежен

При делении на n остатков всего n возможных: 0, 1, …, n − 1. Если встретился остаток 0 — дробь конечная. Если нет, то не позже чем через n − 1 шаг какой-то остаток повторится, и цифры пойдут по кругу. Значит, любое рациональное число записывается конечной или бесконечной периодической десятичной дробью.

Конечную дробь тоже можно считать периодической: 0,5 = 0,5(0). Поэтому коротко говорят: рациональные числа — это периодические десятичные дроби.

Когда дробь конечная

Несократимая дробь m/n записывается конечной десятичной дробью тогда и только тогда, когда в разложении знаменателя n на простые множители есть только 2 и 5.

7/40 = 0,175 (40 = 2³·5); 1/6 = 0,1(6) (в 6 есть множитель 3).

Будь внимателен

Признак работает только для несократимой дроби. 9/75 кажется «плохой» из-за 75 = 3·5², но 9/75 = 3/25 = 0,12 — конечная. Сначала сократи, потом смотри на знаменатель.

Периодическая дробь в обыкновенную

Идея одна: умножить число на 10, 100, 1000… так, чтобы периоды «совпали», и вычесть — бесконечный хвост исчезнет.

Пример 1 · чистый период

Записать 0,(27) обыкновенной дробью.

Решение

Пусть x = 0,2727… Период из двух цифр — умножаем на 100: 100x = 27,2727… Вычитаем: 100x − x = 27, 99x = 27, x = 27/99 = 3/11.

Пример 2 · с целой частью

Записать 2,(18) обыкновенной дробью.

Решение

2,(18) = 2 + 0,(18) = 2 + 18/99 = 2 + 2/11 = 24/11.

Пример 3 · смешанная периодическая

Записать 0,2(45) обыкновенной дробью.

Решение

x = 0,24545… Сначала «сдвигаем» предпериод: 10x = 2,4545…, затем период: 1000x = 245,4545… Вычитаем: 990x = 243, x = 243/990 = 27/110.

Полезно запомнить (для проверки)

0,(a) = a/9   ·   0,(ab) = ab/99   ·   0,(abc) = abc/999

Например, 0,(7) = 7/9, 0,(36) = 36/99 = 4/11.

Будь внимателен

Частые ошибки: умножают на 10 вместо 100 при периоде из двух цифр; в смешанной дроби вычитают x вместо 10x; забывают сократить ответ.

Разбор примеров

Сравнить 0,(45) и 0,4(5). Переводим: 0,(45) = 45/99 = 5/11; 0,4(5) = 41/90. Приводим к общему знаменателю 990: 450/990 и 451/990. Значит, 0,4(5) больше. Можно проще — сравнить цифры: 0,4545… и 0,4555… отличаются в третьем знаке.

Задачи урока

Реши в тетради. Ответы разберём на занятии.

№ 1Запиши в виде десятичной дроби: а) 7/8; б) 4/9; в) 5/6; г) 13/11.
№ 2Не выполняя деления, определи, какие дроби записываются конечной десятичной дробью: 3/40, 7/30, 9/75, 11/14.
№ 3Запиши обыкновенной дробью: а) 0,(7); б) 0,(36); в) 1,(3); г) 0,1(2).
№ 4Вычисли, переведя дроби в обыкновенные: а) 0,(3) + 0,(6); б) 0,(1) · 9; в) 0,(6) · 1,5.
№ 5Сравни 0,(45) и 0,4(5).
№ 6Найди период дроби 1/7 и его длину. Какая цифра стоит на 20-м месте после запятой?

Из учебника

  • № 1 — Записать обыкновенные дроби в виде десятичных: 2/3, 8/11, 3/5, 13/99 и другие.
  • № 2 — Выполнить действия и записать результат десятичной дробью.
  • № 3 — Записать периодические дроби обыкновенными: 0,(6), 1,(55), 0,1(2), −3,(27).
  • № 4–5 — Длинные вычисления со смешанными дробями — техника счёта без калькулятора.

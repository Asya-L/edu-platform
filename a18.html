Алгебра · Алимов · § 18

Логарифмическая функция, её свойства и график

Алимов Ш. А., Колягин Ю. М., Ткачёва М. В. и др. Алгебра и начала математического анализа. 10–11 классы. Просвещение, 2023. · страницы 100–104. Объяснения, примеры и задания подготовлены для урока.

Урок на 80 минут.

После урока получится:

  • Определять область определения и множество значений.

Теория

1. Логарифм становится функцией

Зафиксируем основание a. Каждому положительному x соответствует ровно один показатель y, для которого ay = x. Так появляется функция y = loga x. Логарифм отвечает на вопрос «В какую степень возвести a, чтобы получить x?».

Три обязательных условия: a > 0, a ≠ 1, x > 0. Основание в этом уроке — постоянное число, аргумент x меняется.

Например, log2 8 = 3, потому что 2³ = 8. Запись log−2 8 в рассматриваемом курсе не определена; основание 1 тоже недопустимо.

2. Где определена функция и какие значения принимает

D(f) = (0; +∞), E(f) = ℝ. Число x должно быть положительным, но ответ y может быть отрицательным, нулём и положительным. Для любого y подходит x = ay > 0.

Все графики проходят через (1; 0), потому что a⁰ = 1. Ось Oy, то есть прямая x = 0, — вертикальная асимптота: график подходит к ней всё ближе, но точек с x = 0 у него нет. Функция не ограничена ни сверху, ни снизу; на своей области определения непрерывна.

3. Основание определяет направление графика

ОснованиеКак меняется y при росте xЗнак при x > 1
a > 1ВозрастаетПоложительный
0 < a < 1УбываетОтрицательный

При 0 < x < 1 знаки противоположны. При x = 1 значение равно нулю. Например, log₂(1/4) = −2, а log1/2(1/4) = 2.

Проверьте графики по точкам: для основания 2 получаем (1/2; −1), (1; 0), (2; 1), (4; 2). Для основания 1/2 значения y имеют противоположный знак.

4. Сравниваем логарифмы и используем однозначность

Сначала убедитесь, что основания одинаковые и допустимые, а оба аргумента положительны. При a > 1 большему аргументу соответствует больший логарифм; при 0 < a < 1 — меньший. Поэтому log₂ 6 < log₂ 10, но log1/2 6 > log1/2 10.

Равенство loga u = loga v при допустимом a и положительных u, v равносильно u = v. Строгая монотонность не позволяет двум разным аргументам иметь одинаковое значение.

5. Логарифмическая и показательная функции обратны

Записи y = loga x и x = ay означают одно и то же. Если поменять x и y местами, получим обратную функцию y = ax. Их графики симметричны относительно прямой y = x. Например, точке (8; 3) логарифмического графика соответствует (3; 8) показательного.

6. Преобразования и ограничения

В y = loga(x − h) + k график сдвигается на h вправо и на k вверх (отрицательные h или k означают обратное направление). Сначала найдите D: x − h > 0. Асимптота после сдвига — x = h.

Не переносите условие x > 0 механически на сложный аргумент: для log₃(7 − x) требуется именно 7 − x > 0, то есть x < 7. Внутренняя функция также влияет на монотонность. Область (0; +∞) не симметрична относительно нуля, поэтому обычная логарифмическая функция не является ни чётной, ни нечётной.

Разбор примеров

Строим график без калькулятора

Постройте y = log₂ x и укажите его область определения и нуль.
Выберем степени двойки: x = 1/4, 1/2, 1, 2, 4. Получаем y = −2, −1, 0, 1, 2. Отмечаем точки и соединяем возрастающей плавной кривой только при x > 0. D = (0; +∞), нуль x = 1; ось Oy — асимптота.

Основание меньше единицы

Сравните log1/2 3 и log1/2 7, не вычисляя их.
Оба аргумента положительны, основание 1/2 находится между 0 и 1. Функция убывает. Из 3 < 7 следует log1/2 3 > log1/2 7. Оба значения отрицательны, потому что аргументы больше 1.

Сдвиг и новый нуль

Исследуйте y = log₂(x − 3) + 1: найдите D, асимптоту и нуль.
Нужен положительный аргумент: x − 3 > 0 ⇒ x > 3. График y = log₂ x сдвигаем вправо на 3 и вверх на 1; асимптота x = 3. Для нуля log₂(x − 3) = −1 ⇒ x − 3 = 1/2 ⇒ x = 7/2. Область значений по-прежнему ℝ, функция возрастает.

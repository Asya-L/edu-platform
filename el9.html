Случайные величины

распределение, математическое ожидание, дисперсия, стандартное отклонение, свойства

▶ Презентация Рабочий лист Домашнее задание

Распределение

Определение

Случайная величина X принимает числовые значения x₁, x₂, …, xk с вероятностями p₁, p₂, …, pk. Таблица «значение — вероятность» называется распределением. Всегда p₁ + p₂ + … + pk = 1.

x1234
p0,10,30,4?

Неизвестная вероятность: 1 − (0,1 + 0,3 + 0,4) = 0,2.

Математическое ожидание

Формула

E(X) = x₁p₁ + x₂p₂ + … + xkpk — «среднее значение с весами».

Пример 1

X принимает значения −1, 0, 2 с вероятностями 0,2; 0,5; 0,3. Найдите E(X).

Решение

−0,2 + 0 + 0,6 = 0,4.

Пример 2

X — число очков на игральном кубике. Найдите E(X).

Решение

(1 + 2 + … + 6)/6 = 3,5.

Дисперсия и стандартное отклонение

Формулы

D(X) = E((X − E X)²) = E(X²) − (E X)².   σ(X) = √D(X).

Пример 3

X принимает значения 0 и 2 с вероятностями 0,5 и 0,5. Найдите D(X) и σ(X).

Решение

E X = 1, E(X²) = 0 · 0,5 + 4 · 0,5 = 2 → D = 2 − 1 = 1, σ = 1.

Будь внимателен

Частые ошибки: забыть возвести E X в квадрат; написать D(X) = E(X²) без вычитания; считать σ = D. Дисперсия не бывает отрицательной — если вышло < 0, ищите ошибку.

Свойства

СвойствоПример
E(aX + b) = a · E X + bE X = 3 → E(2X + 5) = 11
D(aX + b) = a² · D XD X = 4 → D(3X − 1) = 36
E(X + Y) = E X + E Yдля любых X и Y
D(X + Y) = D X + D Yтолько для независимых X и Y

Число успехов в n испытаниях

Если событие происходит с вероятностью p в каждом из n независимых испытаний, то среднее число успехов E = np, а дисперсия D = np(1 − p).

Пример 4

Монету бросают 10 раз. X — число орлов. Найдите E(X) и D(X).

Решение

E = 10 · 0,5 = 5; D = 10 · 0,5 · 0,5 = 2,5.

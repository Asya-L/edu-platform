Алгебра · урок 5

Степень с рациональным и действительным показателем

§ 5 · a^(m/n) = ⁿ√(aᵐ), свойства степеней, сравнение

▶ Презентация Рабочий лист Домашнее задание

Теория

Повторение: целый показатель

an = a·a·…·a (n раз), a⁰ = 1, a−n = 1/an (a ≠ 0). Например, 2⁻³ = 1/8, (2/3)⁻² = 9/4.

Откуда берётся дробный показатель

Хотим, чтобы свойство (ap)q = apq работало и для дробей. Тогда (51/3)³ = 5¹ = 5, то есть 51/3 — это число, куб которого равен 5, иначе говоря ³√5. Так возникает определение.

Определение

Для a > 0, целого m и натурального n ≥ 2:   am/n = n√(am).

Также 0r = 0 при рациональном r > 0.

Примеры: 91/2 = √9 = 3; 82/3 = ³√64 = 4 (удобнее: (³√8)² = 4); 16−1/4 = 1/⁴√16 = 1/2.

Будь внимателен

Основание степени с дробным показателем должно быть положительным. Запись (−8)1/3 считается не определённой, хотя ³√(−8) = −2 существует. Причина: 1/3 = 2/6, и тогда (−8)2/6 = ⁶√64 = 2 — получилось бы противоречие.

Пример 1 · вычисление

Вычислить 272/3, 320,4, 81−0,75.

Решение

272/3 = (³√27)² = 9; 320,4 = 322/5 = (⁵√32)² = 4; 81−0,75 = 1/(⁴√81)³ = 1/27.

Свойства степеней

Для a > 0, b > 0 и любых рациональных p, q выполняются те же свойства, что и для целых показателей:

  1. ap · aq = ap+q;   ap : aq = ap−q
  2. (ap)q = apq
  3. (ab)p = apbp;   (a/b)p = ap/bp
Пример 2 · упрощение

Упростить a1/3 · a1/2 : a1/6.

Решение

Показатель: 1/3 + 1/2 − 1/6 = 2/6 + 3/6 − 1/6 = 4/6 = 2/3. Ответ: a2/3.

Пример 3 · формулы сокращённого умножения

Упростить (x1/2 − 3)(x1/2 + 3).

Решение

Разность квадратов: (x1/2)² − 9 = x − 9.

Иррациональный показатель и сравнение степеней

Степень 3√2 определяют через приближения: √2 ≈ 1,4; 1,41; 1,414; … и 31,4, 31,41, 31,414, … приближаются к одному числу ≈ 4,73. Все свойства степеней сохраняются.

Сравнение степеней

1) Если a > 1, то большему показателю соответствует большая степень: 2√3 > 21,7, так как √3 ≈ 1,73 > 1,7.

2) Если 0 < a < 1 — наоборот: 0,53 < 0,52.

3) При одинаковом положительном показателе больше та степень, у которой больше основание: 31/3 > 21/3.

Пример 4 · разные показатели корней

Сравнить ³√3 и √2.

Решение

Приводим к общему показателю 6: ³√3 = ⁶√9, √2 = ⁶√8. Так как 9 > 8, то ³√3 > √2.
